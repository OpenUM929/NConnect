# H1 다음 학습 사전 예측 보고서 — `train_260828-03` (계획)

## 1. 변경 범위

| 항목 | Run 02 | Run 03 계획 |
|---|---:|---:|
| 변경 변수 | `termination_penalty=-50.0` | `termination_penalty=-90.0` |
| 나머지 reward 및 환경 | Run 02 설정 | 변경하지 않음 |
| seed / environments / iterations | 42 / 4,096 / 3,000 | 동일하게 유지 |

변경폭은 권장 범위 `-50 ~ -400` 안에서 `-50`의 2배 절댓값으로 정했다. `-400`으로 한 번에 이동하지 않아, 낙상 벌점 강화의 추가 효과와 부작용을 분리해 관찰한다.

## 2. 근거와 한계

Run 02에서 `termination_penalty=-50.0`은 Run 01 대비 마지막 `base_contact`를 0.9244에서 0.2979로 낮추고, `time_out`을 0.0756에서 0.7024로 높였다. 그러나 `error_vel_xy`는 0.3493에서 0.3596으로, `error_vel_yaw`는 0.2367에서 0.9341로 악화됐다.

따라서 `-90.0`은 **낙상률을 추가로 낮출 수 있다는 가설**을 검증하는 값이며, 최적값이라는 증거는 아직 없다. Run 02 영상 평가는 미완료이므로 실제 보행 품질·부들거림·회전 실패는 미측정이다.

| 항목 | 사전 예측 | 판정 기준 |
|---|---|---|
| 낙상 종료 (`base_contact`) | 감소 또는 유지 | Run 02의 0.2979 미만이면 개선, 이상이면 미개선 |

## 6. 정량 선정 방법과 불확실성

### 6.1 탐색용 용량-반응 모형

이번 내부 실험 목표는 Run 02의 29.79%에서 약 절반인 **15% 이하**로 종료율을 낮추는 것이다. 이는 대회 공식 합격선이 아니라, 낙상 감소와 이미 악화된 yaw 추종 사이에서 과도한 벌점 증가를 피하기 위해 사전 등록한 실험 목표다.

학습 종료 시의 `base_contact` 비율을 `p`, 벌점의 절댓값을 `λ=|termination_penalty|`로 두고, 현재 두 관측값만을 사용한 **탐색용** logit 반응곡선을 다음과 같이 둔다.

`logit(p) = α + β log(λ)`,  `logit(p) = ln(p / (1-p))`

- Run 01: `λ=5`, `p=0.9244`, `logit(p)=2.504`
- Run 02: `λ=50`, `p=0.2979`, `logit(p)=-0.857`
- 두 점에서의 기울기 추정: `β=(-0.857-2.504)/(ln(50)-ln(5))=-1.460`

이 모형에서 사전 목표를 `base_contact=15%`로 두면 `λ≈91.2`가 계산된다. 설정값은 이를 반올림한 `-90.0`으로 고정한다. 이 값의 모형상 예상 `base_contact`는 약 15.3%다.

참고 후보점은 다음과 같다.

| 목표 `base_contact` | 모형상 `λ` | 해석 |
|---:|---:|---|
| 20% | 약 72 | 낙상 감소와 추종 보존 사이의 보수적 후보 |
| 15% | 약 91 | **선택값 `-90.0`의 근거** |
| 10% | 약 125 | 더 강한 생존 제약 후보 |

### 6.2 이 모형이 최적값 증명이 아닌 이유

이 추정은 서로 다른 벌점의 **두 번, 동일 seed 한 번씩**의 학습 결과만 사용한다. 실제 PPO 학습 과정은 비선형이며, `base_contact`는 학습 중 종료 비율이지 고정 시나리오 평가의 낙상 확률이 아니다. 또한 Run 02에서는 yaw 오차가 크게 악화됐다. 따라서 위 수치는 다음 실험의 사전 후보를 정하는 데만 사용하며, `-90`이 최적이라는 결론으로 사용하지 않는다.

### 6.3 제약 다목적 판정

다음 run의 선택 문제는 단일 보상 최대화가 아니라 다음 제약 문제로 다룬다.

`minimize p_fall(λ)`

subject to `error_vel_xy`와 `error_vel_yaw`가 허용 범위 안에 있고, 동일 1,000-step 영상에서 소극적 정지·불필요 회전·낙상이 없어야 한다.

현재 목표 낙상률과 허용 추종 오차의 공식 대회 임계값은 확보되지 않았다. 그러므로 Run 03은 Run 02 대비 낙상 지표가 개선돼도 두 추종 오차가 모두 더 악화되거나 영상에서 회전 실패가 확인되면 채택하지 않는다. 이 조건을 만족하는 후보들만 Pareto 후보로 남긴다.

### 6.4 실행 게이트

**Run 03 값 `-90`은 사전 등록 후보이나, 아직 실행 승인값은 아니다.** Run 02의 동일 조건 1,000-step play 평가로 실제 보행·회전 행동을 먼저 확인한다. 그 평가에서 yaw 위험이 실제로 확인되면, 더 큰 종료 벌점 대신 추종 보상 또는 별도의 보상 항을 다루는 새 가설을 테스트 기획자가 설계해야 한다.
