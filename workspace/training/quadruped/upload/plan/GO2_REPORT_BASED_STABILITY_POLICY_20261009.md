## 1. 사용자 결정과 범위

최신 요청은 앞선 설명대로 튜닝 정책 계획서를 만드는 것이다. 성공 report의 조합을 출발점으로 삼고, 과거 P0·A048로 되돌려 해석하지 않는다. 사용자 요구는 계단·험지를 걷는 능력을 보존하면서 더 안정적으로 만드는 것이다.

이 문서는 정책 계획이다. 새 학습 번호 예약, 실행 ZIP, 서버 실행, PC2 인계, 기존 정책 교체·공식 제출은 수행하지 않는다. 과거 발행물·사전등록·판정은 변경하지 않는다.

## 2. 관측 사실과 원인 설명의 경계

REPORT_READ_STATUS=READ_UNMATCHED.

- 직접 읽은 원문: 루트 `report.html`(학습 시작 2026-10-06 22:27, 종료 23:17, 총 3000 iter, 표시 checkpoint 2400).
- 본문 수치: 최고 보상 16.32(iter 2357), terrain 4.48, 학습 낙상률 23.8%(마지막 10회 평균), 마지막 탐색 std 0.934.
- 사용자 관측: 이 정책은 계단과 험지를 걷는다. 보행 가능성의 출발 근거로 사용한다. 에이전트가 영상을 직접 판독했다거나 공식 G3·G5를 완주했다고 확대하지 않는다.

**원인 검토:** 낙상률·std는 어느 동작에서 왜 불안정한지 설명하지 못한다. 몸통의 지속적인 기울기, 빠른 흔들림, 발 미끄러짐, 착지·지지 상실, 관절 명령 떨림 중 무엇이 남은 문제인지 아직 구분되지 않는다. 우리 다른 정책의 실패 경로를 이 정책의 원인으로 복사하지 않는다.

따라서 "-0.25면 더 안정적이다"는 결론은 없다. 정확한 예측은 **"남은 불안정에 기울어진 몸통 자세가 기여한다면, 그 자세에 대한 벌점 강화가 도움이 될 수 있다"**이다. 인과 미확정은 탐색을 영구 금지하는 이유가 아니지만, 원인이 확인됐다는 표현도 허용하지 않는다.

## 3. 보상 역할 → 예측 → 반례

원문 근거는 `reports/GO2_LECTURE_REWARD_REFERENCE.md` §6·§6-b와 `reports/GO2_TUNING_BASE_DATA.md` §0-1이다(경로는 quadruped 기준).

`flat_orientation_l2`는 몸통 좌표 중력 투영의 x·y 성분 제곱합에 가중치를 곱한다. 기울어진 자세 자체에 대한 벌점이며, 각속도 벌점인 `ang_vel_xy_l2`와 다르다. 배포 설명은 강화 시 몸통 수평·안정, 완화 시 험지 적응이라는 경쟁 방향을 설명한다. 강좌 Go2 주요 항 표에 직접 수록된 항으로 잘못 인용하지 않는다.

- 주 가설: 기울어진 자세에 대한 억제를 늘려 자세 이탈·낙상을 줄이면서 계단·험지 전진을 유지할 수 있다.
- 경쟁 가설: 필요한 pitch·지형 적응까지 억제해 감속·정체·등반 손실을 만든다.
- 무효 가설: 남은 불안정이 이 항으로 개선되지 않거나, 변화가 비교 변동과 구분되지 않는다.
- 값의 산술: -0.2→-0.25면 **동일 자세에서 해당 항 벌점 크기만 25% 증가**한다. 안정성 25% 증가나 새 학습 궤적의 개선 예측이 아니다.

기존 반례: A033에서 flat 0→-0.5인 A047은 험지 감속과 10cm 등반 손실을 보였다(`reports/GO2_REWARD_TRIAL_REFERENCE.md` §3-6). 이 반례 때문에 큰 강화·자동 추가 강화를 피하고 전진·등반 보존을 반드시 함께 본다. 그러나 다른 조합의 -0.25까지 실패로 확정하지 않는다. 새 성공 사례 역시 flat 항 하나의 인과효과를 입증하지 않는다.

## 4. 기준 설정과 조건부 시험값

기준 R은 사용자가 계단·험지 보행을 확인한 report 설정이다. 후보 S는 R의 보상 설정을 재사용해 **한 가중치만 변경하는 탐색 설정**이며, checkpoint 이어 학습을 뜻하지 않는다. 효과 비교 대상도 R이다. 기존 A033·A048은 역사적 반례용이며 S의 채택 대조군이 아니다.

**선정 강도:** S는 조건부 exploratory 후보다. 남은 실패 유형이 확인되지 않아 다른 후보보다 성능 개선 가능성이 높다고 확정하지 않는다. 앞선 "첫 선택"을 검증된 추천처럼 표현한 것은 정정한다.

**폭의 이유와 한계:** 기존에 활성화된 자세 항에서 0.05만큼 벌점을 추가하는 설계값이다. 0→-0.5에서 관측된 감속·등반 손실을 고려해 그 폭을 그대로 적용하지 않는다. 작은 폭·25%·미시험이라는 사실은 개선 근거가 아니며, 정확히 -0.25가 최적이라는 실측 근거는 없다.

## 6. 향후 시험 설계와 판정

이 절은 정책 수준 설계이며 실행 사전등록 완료가 아니다. 발행 시 같은 작업 ID로 실제 정책 identity, 원 설정, seed, 평가 조건·횟수, 정량 문턱, 예산·회수 요건을 확정한다. 확인되지 않은 숫자를 지금 만들어 넣거나 결과를 본 뒤 문턱을 정하지 않는다.

1. **기준 보존:** R 정책·설정은 별도 보존한다. 후보 파일로 덮어쓰지 않는다. 후보 폐기는 가중치만 되돌리면 기존 policy tensor가 복원된다는 뜻이 아니다.
2. **비교 조건:** 보상 외 설정·학습 길이·checkpoint 선택 규칙·evaluator를 맞춘다. report의 총 3000 iter 조건을 기준으로 설계하며 후보만 1000 iter로 줄여 비교하지 않는다. 학습 길이 변경 실험이나 기존 checkpoint 연장 학습을 자동 추가하지 않는다. best 2400, 최고 보상 시점 2357, 최종 학습 3000을 구분한다.
3. **관측 우선:** 보존된 영상·telemetry가 있으면 먼저 사용한다. 새 계측이 꼭 필요한지는 기존 자료로 가를 수 없는 질문에 한정한다. 이 항목은 새 진단 서버 실행 지시가 아니다.
4. **직접 측정:** G3 험지·G5 계단의 자세 이탈·낙상뿐 아니라 전진·추종·실제 등반을 함께 비교한다. G2 회전·G6 밀침은 보호 대상이다. G1·G4·G7은 미측정이면 그대로 표기하고 전 축 개선으로 확대하지 않는다.
5. **판정 분리:** 기울기만 줄면 보조 관측이다. 보행 보존과 안정 개선을 함께 만족해야 INTERNAL_GATE_PASS로 판단할 수 있다. 영상·내부 정량·공식 결과는 각각 기록한다. 현재는 전부 새 비교 미측정이며 VIDEO_OBSERVED를 에이전트가 직접 확인한 것처럼 쓰지 않는다.
6. **개선:** 같은 조건의 전진·등반·추종을 보존하며 안정성이 개선되면 S를 후속 평가 후보로 유지한다. 자동 최종 채택·공식 제출은 하지 않는다.
7. **손실/악화:** 덜 넘어져도 느려지거나 계단을 못 오르면 INTERNAL_GATE_FAIL. R 정책·설정을 유지한다. 평가 중 보행 붕괴가 명확하면 기존 안전 중단 규칙을 적용하고 실패 자료를 보존한다.
8. **무변화/불명확:** INTERNAL_GATE_INCONCLUSIVE. R 유지. -0.3·-0.5 자동 추가 강화나 다른 변수 자동 변경은 하지 않는다. 무엇이 판정을 가르지 못했는지 기록한다.

## 7. 실행 범위·수집 계약

추후 패키지를 별도 요청받으면 번호 충돌 확인·사전등록·로컬 검증 후 발행한다. 배포 학습 코드는 수정하지 않으며 R-6에 따라 가중치만 변경한다. 설정·정책의 출처와 R-7 준수는 공식 제출 판단에서 별도 확인한다. 다른 사람의 설정·정책을 그대로 제출하는 계획이 아니다.

새 학습을 실행하는 경우 해당 run의 원 report.html·로그·전체 env·checkpoint·policy identity·필수 영상·telemetry·SHA/manifest를 회수한다. 영상과 report 회수가 빠진 상태에서 회수 완료·서버 종료 가능을 선언하지 않는다. 실행 시간·비용과 구체적 회수 경로는 실행 패키지 사양에서 확정하며 이 계획서로 서버 착수를 지시하지 않는다.

## 8. 이번 계획의 결론

**성공 조합을 유지하고, 기울어진 몸통 자세가 남은 문제에 기여한다는 조건부 가설 아래 flat_orientation_l2 -0.25를 시험 후보로 둔다. 정확한 값의 개선은 미입증이다. 계단·험지 보행을 희생한 낙상 감소는 채택하지 않으며, 실패·불명확 시 성공 기준 R을 유지한다.**
