16. policy.pt 파일 준비하기

학습이 끝나면 최종 산출물인 policy.pt를 만들고 예선에 제출해요. 서버 상태에 따라 제출 방법이 달라지니 두 가지 경우를 모두 살펴봐요.

①

생각 열기

학습이 끝났다고 끝이 아니에요. 최종 산출물인 policy.pt를 만들어 예선에 제출해야 해요.

학습 결과를 제출 가능한 형태로

학습을 마치면 로그 폴더에 model_0.pt, model_100.pt와 같은 여러 체크포인트들이 쌓여요. 대회 시스템은 그 중 성능이 가장 좋았던 것을 자동으로 골라 model_best.pt로 저장해줘요. 이 파일로 play.py를 실행하면 실제 로봇에 올릴 수 있는 policy.pt가 만들어지고, 이걸 예선에 제출해요.

학습 → model_best.pt 자동 선정 → play.py 실행 → policy.pt 생성 → 예선 제출.
②

학습 목표

01
model.pt와 policy.pt의 차이를 설명할 수 있어요.
02
어느 상황에서든 policy.pt를 만들 수 있어요.
03
대회 대시보드에서 예선 제출을 완료할 수 있어요.
③

개념 만나기

학습이 남기는 .pt 파일들이 각각 무엇인지, 그리고 model_best.pt와 policy.pt가 어떻게 다른지 정리해요.

학습이 남기는 세 가지 .pt 파일

학습이 진행되면 역할이 다른 .pt 파일들이 만들어져요.

파일무엇을 담나쓰임
model_XXXXX.pt가중치 + 옵티마이저 + iteration 정보매 N번마다 자동 저장되는 학습 체크포인트
model_best.pt지금까지 성능이 가장 좋았던 체크포인트대회 시스템이 자동 선정해 exported 폴더에 보관
policy.ptactor 신경망 가중치만play.py 실행으로 생성, 예선 제출과 초월 챕터에 사용
체크포인트를 직접 비교·선택할 필요 없어요. 대회 시스템이 가장 좋은 체크포인트를 model_best.pt로 자동으로 뽑아줘요.

model_best.pt와 policy.pt의 차이

둘 다 학습된 신경망이지만, 담긴 내용과 용도가 달라요.

비교model_best.ptpolicy.pt
포함 내용가중치 + 옵티마이저 + 메타데이터actor 가중치만
파일 크기크다작다
용도중단된 학습 이어서 학습(resume) 가능로봇 제어 전용
생성 시점학습 중 대회 시스템이 자동 생성play.py 실행 후 생성
④

직접 해보기

서버 상태에 따라 두 가지 방법으로 policy.pt를 만들고, 예선에 제출해요.

예선 제출

policy.pt가 준비됐으면 대회 대시보드에서 제출해요.

  1. robotics.connect.or.kr 대시보드로 이동해요.
  2. 로봇 유형(H1 휴머노이드 또는 Go2 사족)을 선택해요.
  3. policy.pt를 업로드해요.
  4. env.yaml을 업로드해요.
  5. 전략 및 변경 사항을 상세히 작성해요. (보상 설계 의도, 바꾼 항목 등)

⑤

스스로 다지기

진화 챕터 한눈에 정리

  • 강화학습은 정답 동작 대신 보상을 주고, 시행착오로 스스로 배우게 해요. 핵심은 정책·환경과 행동·관측·보상의 반복 루프예요.
  • 학습 목표는 보상 함수로 번역해요. 항목을 더하고 빼면서 점수와 함께 영상으로도 결과를 확인해요.
  • Go2(사족)·H1(휴머노이드) 중 하나를 골라 수천 대를 병렬로 돌려요.
  • 본 학습 전 짧은 smoke test로 환경이 도는지 확인하고, tmux로 서버 접속이 끊겨도 이어지게 해요.
  • TensorBoard로 보상·loss·fps·탐색 강도를 살펴보고, 발산·정체·Reward Hacking 등 이상 신호를 잡아 보상을 조정해요.
  • 보상·환경이 그대로라면 resume(추가 학습), 바꿨다면 처음부터 재학습해요.
  • 대회 시스템이 model_best.pt를 자동 선정하면, play.py로 policy.pt를 만들어 예선에 제출해요.
다음 강 안내

진화 챕터에서 만든 정책이 "걷기"를 알지만, 어디로 갈지는 몰라요. 초월 챕터에서는 LLM을 로봇의 대뇌로 연결해, 카메라가 본 장면을 보고 자연어로 판단·명령을 내리게 만들어요.

처음 보시는 분들도
천천히 따라오면 돼요

21강짜리 가이드북이에요. 가상 로봇을 만드는 것부터 시작해서, 감각을 달고, 스스로 걷는 법을 가르치다 보면, 끝에는 말 한 마디로 움직이는 자율 로봇이 손에 남아요. 하루에 한 강씩 가도 좋고, 주말에 몰아서 봐도 좋아요. 본인 페이스로요.

쓰는 법
    01

    챕터부터 하나 골라요

    탄생 → 각성 → 진화 → 초월, 이 네 묶음이에요. 처음이면 그냥 1번 탄생부터 들어가시면 돼요. 좌측 목차에서 네 챕터가 한눈에 보여요.

    02

    강의 안에서 넘어다녀요

    강의는 글과 코드가 섞인 형태예요. 좌측 사이드바에서 강을 옮겨다닐 수 있고, 키보드 ← →로도 됩니다. 모바일이면 상단 드롭다운으로 강을 바꿔주세요.

    03

    코드는 직접 돌려보세요

    글로만 읽으면 잊혀요. 강의 안 Python 코드는 Isaac Sim에 그대로 붙여 돌리면 됩니다. 한 번씩 직접 돌려본 사람만 다음 강을 편하게 봐요.

    04

    끝까지 가면 본선이에요

    21강을 다 마치면 자율로 걸어다니는 휴머노이드 로봇이 손에 남아요. 그걸 들고 네이버 커넥트 로보틱스 본선에 나가시면 됩니다.
