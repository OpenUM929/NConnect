### 판정

**PARTIAL (학습 지표 기준, 영상 평가 대기).**

- 예상한 방향대로 낙상 종료가 줄고 시간 종료와 terrain progression이 증가했다.
- 사전에 부작용 기준으로 지정한 두 추종 오차가 모두 악화됐으며, 특히 `error_vel_yaw` 악화 폭이 크다.
- PASS에 필수인 1,000-step 영상 무낙상 여부가 아직 미측정이다.

따라서 `termination_penalty=-50.0`이 Run 01보다 낙상 억제와 curriculum 진행에 유리한 결과를 보였다는 사실은 기록할 수 있다. 그러나 안정 보행, 명령 추종, H1~H7 개선 또는 최종 제출 적합성을 확정할 수는 없다.

## 4. 진단 가설과 반증 한계

### 확인된 방향

단일 reward 변경 조건에서 `base_contact`가 크게 감소하고 `time_out`이 증가했다. 이는 낙상 비용 강화가 학습 중 생존 우선 행동을 유도했을 가능성과 일치한다.

### 부작용 가설

`error_vel_xy`와 `error_vel_yaw`가 악화됐으므로 정책이 명령 추종보다 생존을 우선했을 가능성이 있다. 특히 yaw 오차 증가는 회전 명령을 충분히 수행하지 않거나 잘못된 회전 행동을 보일 위험 신호다. 탐색 std 증가도 정책의 무작위성이 충분히 줄지 않았을 가능성을 보이지만, std 하나만으로 실제 흔들림이나 발산을 확정하지 않는다.

### 반증·해석 한계

- Run 02 평가 영상이 없어 제자리 버티기, 소극적 이동, 회전 실패, 실제 낙상 여부를 확인할 수 없다.
- Run 01·02 모두 seed 42 단일 실행이므로 차이의 반복 재현성을 알 수 없다.
- 종료율·terrain·추종 오차는 마지막 iteration 값이고, 최고 reward는 iter 2,776 값이다. 서로 같은 checkpoint 시점의 동시 측정값이 아니다.
- H1~H7 격리 평가 metrics가 없으므로 대회 시나리오 성능으로 환산하지 않는다.

필수 확인 항목은 다음과 같다.

1. 1,000-step 무낙상 여부와 실제 생존 시간

4. 큰 yaw 오차가 영상의 회전 실패 또는 불필요 회전으로 나타나는지 여부
