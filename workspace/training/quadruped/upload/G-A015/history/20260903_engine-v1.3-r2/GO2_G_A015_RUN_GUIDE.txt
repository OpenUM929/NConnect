GO2 G-A015 SERVER RUN GUIDE — Pilot-01 baseline, feet_air_time 0.20 -> 0.35

WHY THIS BASELINE
Every screening run so far compared a candidate against Default-01, which the 69-case
posture_gate_v2 suite measures at 17.90697/70. The same suite measures the frozen Pilot-01
at 33.79311/70 (G-A012, verified). Screening against Default-01 therefore optimises a policy
we would never submit. Engine 1.2.0 ships both frozen baselines and this experiment screens
against Pilot-01.

WHY THIS VARIABLE
Pilot-01's weighted point loss ranks G3 12.97 > G5 10.50 > G4 4.95 > G7 3.61 > G2 2.60 >
G1 1.13 > G6 0.45 (/70), and the G3 and G5 losses are survival-dominated: rough_lateral falls
in up to 23 of 32 envs and stairs_15_down falls in 32 of 32. Pre-registration GO2_CAMPAIGN_
SCHEDULE.md section 15-c selects the single largest weighted loss, which is G3. feet_air_time
raises foot clearance, which is the one dial that acts on both G3 and G5, and it is the only
variable with a measured curve: 0.01 -> 0.20 moved the same 69-case suite by +3.8656/70 with
no survival regression on any scenario. This run adds the third point on that curve.

WHY NOT THE PRE-REGISTERED G-A014
G-A013 measured flat_orientation_l2 0.0 -> -1.0 at -1.4278/70. The failure was not a weak
effect but a wrong-signed one: G3 survival +0.156 and G7 +0.250, against G4 -0.313,
G5 -0.313, G2 -0.188 and G6 -0.125. On a +20 degree slope and on stairs the base must pitch
with the terrain, and this term penalises exactly that. G-A014 would have doubled the weight
in the direction measured to be harmful, so it is cancelled and recorded as cancelled.
