### 5-1. 값 근거 — 왜 −1.0인가

upstream Go2 rough 부모값 0.0과 배포 주석의 권장범위 0~−2는 근거로 쓰지 않는다. −1.0이 그 범위의 중간값과 **우연히 같지만**, 선택 근거는 아래 크기 계산이다(기체 AGENTS §4-2).

| 상태 (A017 평가 중 q) | −0.5 | **−1.0** | −2.0 |
|---|---:|---:|---:|
| 평지 보행 q .018 | −.009 | −.018 | −.036 |
| 험지·경사·계단 평균 q .03~.06 | −.015~−.03 | **−.03~−.06** (기존 벌점합 .577의 5~10%) | −.06~−.12 |
| 20° 경사 정렬 q .117 | −.059 | −.117 (추종 .886의 13%) | −.234 (26%) |
| **종료 직전 q .63~.69** | −.31~−.35 (추종의 35~39%) | **−.63~−.69 (추종의 71~78%)** | −1.26~−1.38 (추종 초과) |

값은 모두 초당 가중 크기다. `Episode_Reward`는 에피소드 합을 에피소드 최대 길이로 나눈 값이므로 대략 초당 평균으로 비교했다.

아래는 모두 **크기 계산**이다. 세 값의 행동 효과 차이는 측정된 적이 없다.
- **−1.0:** 계산상 평상시 벌점은 기존 벌점 합의 10% 이하다. 종료 직전 상태의 벌점 크기는 추종 보상과 비슷하다.
- **−0.5:** 계산상 실패 직전 벌점 크기가 −1.0의 절반(추종의 35~39%)이다. "약해서 효과가 없다"는 뜻이 아니다.
- **−2.0:** 계산상 실패 직전 벌점이 추종을 넘는다. 경사면에서도 상시 추종의 26% 크기다. 정체나 경사 회피 위험이 −1.0보다 크다고 **추정**한다.
- 따라서 −1.0은 효과가 입증된 값이 아니라 크기 비교로 고른 **탐색값**이다.
- **한계:** q 분포는 A017 정책의 평가 분포다. 벌점이 들어가면 정책과 학습 지형 분포가 달라진다. 최적값 추정이 아니라 `exploratory` 설계값이다.

## 10. 재현 코드 (저장소 루트, 표준 라이브러리, 읽기 전용)

```python
import csv, collections, statistics as st
from pathlib import Path
W = 25  # 0.5 s
def q(r): return max(0.0, 1 - float(r["proj_grav_z"]) ** 2)
def tilt(path):
    rows = collections.defaultdict(list)
    with path.open() as f:
        for r in csv.DictReader(f): rows[r["env_id"]].append(r)
    first = {}
    for e, rs in rows.items():
        for i, r in enumerate(rs):
            if r["terminated"] == "1" and r["term_time_out"] != "1": first.setdefault(e, i)
    surv = [e for e in rows if e not in first]
    pre, ctl = [], []
    for e, i in first.items():
        if i < W: continue
        pre += [q(r) for r in rows[e][i - W:i]]
        for s in surv: ctl += [q(r) for r in rows[s][i - W:i]]
    return len(first), st.mean(pre) if pre else None, st.mean(ctl) if ctl else None
base = Path("workspace/_keep/go2_a017_full_suite/evaluation/a017/cases")
for seed in (101, 202, 303):
    print(seed, tilt(base / f"seed_{seed}/rough_lateral/steps.csv"))
# 기대: 101 (17, .688, .015) · 202 (14, .628, .027) · 303 (17, .660, .017)
```

전체 표(§3-2·3-3·3-5)는 같은 함수를 case·arm별로 돌린 결과다. q 전체 평균은 t≥0.5 s 전체 행, "1초 전 창"은 [i−50, i−25) 행이다.
