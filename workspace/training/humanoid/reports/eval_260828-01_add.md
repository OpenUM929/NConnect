# H1 강화학습 1차 평가 분석 보고서

> **문서 역할:** baseline 정책의 단일 play 영상을 사실대로 기록하고 다음 run의 영상 비교 기준을 사전 등록한다. H1~H7 정식 평가 또는 최종 제출 보고서가 아니다.

## 1. 평가 대상과 근거

| 항목 | 값 | 근거 |
|---|---|---|
| RUN_ID | `train_260828-01` | 학습 보고서 연결 키 |
| 입력 checkpoint | `exported/model_best.pt` | play 터미널 출력 |
| 생성 정책 | `exported/policy.pt` | play 종료 `exit=0` 및 export 완료 출력 |
| 평가 방식 | `play.py --headless --video --video_length 1000 --enable_cameras` | 사용자 제공 play 터미널 출력 |
| 평가 영상 | `exported/play_video.mp4` | export artifact |
| 실행 결과 | subprocess `exit=0`; policy·영상 export 완료 | 사용자 제공 play 종료 출력 |

## 2. 관찰 사실

사용자가 `exported/play_video.mp4`를 확인해 다음과 같이 관찰했다.

- 약 17초 동안 자세를 유지하려고 부들거렸다.
- 자세 보정 과정에서 회전했다.
- 이후 넘어졌다.

이 영상은 단일 rollout이다. 명령별 조건과 H1~H7 시나리오가 분리되지 않았으므로 “17초 생존”을 H1 생존 시간이나 전체 생존률로 환산하지 않는다.

## 3. 근거와 해석

| 관찰 | 관련 학습 근거 | 해석 범위 |
|---|---|---|
| 부들거림·자세 보정 회전 | 탐색 std 0.888, `error_vel_yaw=0.2367` | 정책이 안정적으로 수렴했다는 근거가 부족함. 회전 원인을 특정 reward로 확정할 수는 없음 |
| 약 17초 후 낙상 | `base_contact=0.9244`, `time_out=0.0756` | 단일 영상의 낙상과 학습 종료 통계가 방향상 일치 |
| export 성공 | `policy.pt`, `play_video.mp4` 존재 | 실행 파이프라인 성공만 증명하며 보행 성능은 증명하지 않음 |

## 4. Baseline 평가의 예측-결과 비교

이 평가 전에 영상 행동, 생존 시간 또는 통과 기준을 기록한 사전 예측이 없었다. 따라서 “예측이 맞았다/틀렸다”는 판정을 하지 않는다.

| 사전 예측 | 실제 결과 | 비교 결론 |
|---|---|---|
| 기록 없음 | 약 17초간 부들거림·회전 후 낙상 | 예측 비교 불가; 실제 영상 성능은 FAIL |

## 5. 평가 판정

**FAIL (baseline 영상 성능 판정).**

1,000-step 영상 구간에서 낙상 없이 자세를 유지하지 못했고 안정 보행을 보이지 못했다. 이 정책은 다음 개선 실험의 비교 영상으로 보관하되 최종 제출 후보로 채택하지 않는다.

## 6. 다음 run 영상 사전 예측과 검증 계획

대상은 `termination_penalty: -5.0 → -50.0`만 변경한 `train_260828-02`이다. 학습 보고서의 사전 예측과 동일한 기준을 사용한다.

| 항목 | baseline 실제 결과 | 다음 run 사전 예측 | 판정에 사용하는 기준 |
|---|---|---|---|
| 영상 완료 | 약 17초 후 낙상 | 생존 시간 증가 | 1,000-step 영상 무낙상 완료 시 기대효과 충족 |
| 부들거림 | 관찰됨 | 감소 | baseline과 나란히 비교해 감소 여부 기록 |
| 불필요한 회전 | 관찰됨 | 감소 | 명령 추종 회전과 자세 보정 회전을 구분해 기록 |
| 전진·회전 추종 | 정량 미측정 | 심각한 악화 없음 | 영상만으로 수치화하지 않고 학습 오차 지표와 함께 판단 |
| 예상 부작용 | 기준 없음 | 소극적 움직임 또는 제자리 버티기 | 무낙상이어도 명령을 거의 수행하지 않으면 PARTIAL |

다음 평가도 `--headless --video --video_length 1000 --enable_cameras` 조건을 유지한다. best checkpoint 선정·export 절차, 명령 샘플링 조건, seed 또는 영상 길이가 달라지면 차이를 reward 하나의 효과로 확정하지 않고 `INCONCLUSIVE` 가능성을 기록한다.

## 7. H1~H7 상태와 한계

- H1~H7: 모두 미측정.
- `eval_260828-01_metrics.csv`가 없어 생존률, 목표/실제 속도, 기울기와 회복 시간을 정량 비교할 수 없다.
- 영상 관찰 문장은 사용자 관찰 기록이며, 수행하지 않은 프레임별 측정이나 시나리오별 평가는 추가하지 않았다.
