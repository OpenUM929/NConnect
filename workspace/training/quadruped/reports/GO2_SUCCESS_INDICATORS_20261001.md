# Go2 성공 지표 → 보상 변수별 지표 변화 → 성공 사례 정리 (2026-10-01)

사용자 요구: 성공을 위한 지표를 시나리오 전체에서 모으고, 그 지표가 어떤 보상 변수를 바꿀 때 변하는지 추출하고, 성공 사례를 정리한다.
- 새 실행 없음. 기존 회수물 steps.csv·summary.json으로 만든 증거만 다시 묶었다.
- 도구 `tools/go2_success_indicators.py`. 증거 `evidence/go2_success_indicators_20261001/INDICATORS.csv`(정책×시나리오 72행)·`REWARD_DELTAS.csv`(보상 한 항 변경 쌍).
- 판정은 내부 자세 게이트 기준이다(영상 확인 아님). 모든 정책은 학습 seed 42 한 번이다.

## 0. 먼저 읽을 한계 — 보상 없이 생긴 차이의 크기 [확인]
같은 보상·같은 seed로 서버 A048과 PC A048이 다르게 학습됐다. 보상 변경이 없는데도 지표가 아래만큼 달라졌다.
- 험지 옆 성공 −52
- 15cm ≥2단 −18
- 10cm 첫 디딤판 몸높이 회복 +38
- 몸높이 +0.05~0.13 m
아래 보상 쌍의 차이 가운데 **이 크기보다 작은 것은 보상 효과와 학습 흔들림을 가를 수 없다.** 큰 차이만 신호로 읽는다.

## 2. 보상 변수를 바꿀 때 지표가 어떻게 변했나 (REWARD_DELTAS.csv)
**`lin_vel_z_l2` 약화 (A033 −2.0 → −1.75 / −1.5 / −1.375 / −1.25 / −1.0)**
- 일관되게 변한 것 [확인]:
  - 초기 기울기 감소(험지 전진 −5.4~−7.7°, 우회전 −1~−7°, 계단 −2.9~−5.7°)
  - 속도 증가(험지 전진 +0.02~+0.08, 우회전 최대 +0.10)
  - 험지 전진·우회전 추종 개선(−0.04~−0.10)
- 값마다 갈린 것:
  - 15cm 성공: −1.5만 +46(첫 디딤판 몸높이 회복 +55대, 모서리 뒤 상승 +0.107 m). −1.25는 +3, 나머지는 0.
  - 10cm 성공: −1.5 +48, −1.25 +35, −1.0 +23, −1.75 −11, −1.375 −26.
  - 험지 옆 성공: −1.5·−1.375·−1.25는 +35~+43, −1.0은 +13, −1.75는 −21.
  - 우회전: −1.5만 기울기 판정 +29.
  - 밀침: −1.75만 −44, 나머지 +11~+21.
- 읽기: 기울기·속도·추종은 값 순서대로 한 방향으로 움직였다. 성공 지표는 값마다 뒤집혔다. 계단 15cm 성공 지표(첫 디딤판 몸높이 회복)를 만든 설정은 −1.5 하나다.

**`ang_vel_xy_l2` 강화 −0.08 (A033 기준, A043 기준) / 완화 −0.04 (A033 기준)**
- 계단 10·15cm 성공은 세 변경 모두 감소했다(−29 / −31 / −79, 15cm는 A043 기준에서 −46). 첫 디딤판 몸높이 회복도 모두 감소했다(−28 ~ −59).
- 험지 옆 성공은 기준에 따라 뒤집혔다. A033 기준 강화는 +41, A043 기준 강화는 −26, 완화는 +7.
- 우회전 기울기 판정은 A043 기준 강화에서 29 → 0이었다. 기울기 크기는 +4.5°로 오히려 늘었다.

**`flat_orientation_l2` 0 → −0.5 (A033 기준)**
- 기울기 감소(−2.8~−6.5°), 속도 감소, 추종 악화(험지 전진 +0.25).
- 계단 10cm 성공 −31. 15cm 판정은 −82(오르지 않아서 줄었다). 험지 옆은 변화 없음.

**`track_lin_vel_xy_exp` 1.5 → 1.6 (A033 기준)**
- 계단 10cm 성공 −31(첫 디딤판 몸높이 회복 −33).
- 험지 전진 성공 −16, 추종 +0.18 악화. 험지 옆 +6.
