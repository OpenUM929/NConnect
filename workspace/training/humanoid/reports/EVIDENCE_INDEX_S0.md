## 2. 정량 지표 — 정규화 병기 (원값 단독 인용 금지)

`humanoid-report-writer.md:51-59`: `error_vel_*`는 `Train/mean_episode_length`로 나눠
**같은 행에 병기**해야 한다. 원값만 적은 표는 미완성이다.
정규화값 = `원값 / ep_len × 500` (`max_command_step = 10.0 s / 0.02 s`).

| 지표 | Run 04 | Run 05 | 변화 |
|---|---:|---:|---:|
| `mean_episode_length` (마지막 500 평균) | 776.88 | 762.61 | — |
| `error_vel_xy` **/step** | 0.2765 | **0.2219** | **−19.7%** |
| `error_vel_yaw` **/step** | 0.4184 | **0.6303** | **+50.6%** |

**statue(명령 무시하고 서 있기) 기준선 대비** — `xy 0.7165` · `yaw 0.6681`:

| | Run 04 | Run 05 |
|---|---:|---:|
| `error_vel_xy` / statue | 0.39x | **0.31x** |
| `error_vel_yaw` / statue | 0.63x | **0.94x — 경계선** |

**가중 판정** — yaw가 걸리는 시나리오는 **H4 하나(0.10)**, xy는 **직진 계열 0.60**:
`0.60 × 19.7 − 0.10 × 50.6 = **+6.78**` → Run 05 우세.
손익분기 각속도 지분 = `0.70 × 19.7 / (50.6 + 19.7) = 0.1963` → **28.0%** (실제 14.3%).

> ⚠️ **위 값은 iter 2999 시점의 학습 집계이고, 제출 정책은 iter 2700이다.** 서로 다른 정책이다.
> 또한 **학습 지형(계단 23cm·박스 50cm 포함) 분포 전체의 집계**이지 예선 시나리오 격리값이 아니다.
