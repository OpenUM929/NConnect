## 1. 한눈에 보는 경기

- 두 팀(🔵블루 / 🔴레드) 로봇이 같은 맵에서 **180초(3분)** 동안 큐브를 모읍니다.
- 한 세트는 **총점이 높은 팀이 승리**. 대결은 **5전 3선승** — **3세트를 먼저 이기는 팀**이
  그 대결의 승자입니다.
- 본선(온라인)에서 **32팀이 1:1 토너먼트** → **상위 4팀**이
  결승(오프라인, 네이버 사옥)에 진출해 우승을 겨룹니다. 결승은 생중계됩니다.
- 당신이 준비하는 것은 **두 가지**:
  1. **로봇 (PT)** — 예선에서 학습한 정책이 기본. **라운드 일정에 맞춰 다시 학습해 교체 가능**
     (선택 — 교체하지 않으면 예선 최종본이 그대로 쓰입니다). 본선 진출팀에는 클라우드 학습 시간이
     추가 부여됩니다. ⚠️ 시리즈가 시작된 뒤에는 정책을 못 바꿉니다.
  2. **LLM 전략** — "어떤 큐브를 어떤 순서로 노릴지" 를 자연어로 (≤300자).
     라운드 사이 **작전 타임(1분)** 에 수정할 수 있습니다.

> 🤖 전략을 해석하는 **LLM(Gemini)은 운영진이 제공**하며 모든 팀에 동일하게 적용됩니다.
> 팀이 별도 LLM 을 반입·연동할 수는 없습니다.

---

## 2. 점수

| 항목 | 점수 |
|---|---|
| 큐브 1개 획득 | **+100** |
| 넘어짐 1회 | **−50** |
| 차량 충돌 1회 | **−30** |

- **총점 = 큐브 − 넘어짐 − 충돌.**
- **동점이면 타이브레이커**(순서대로): ① 큐브 수 많은 팀 → ② 낙상 적은 팀 →
  ③ 충돌 적은 팀 → ④ 첫 큐브를 빨리 먹은 팀 → ⑤ 마지막 큐브를 빨리 먹은 팀.
  (다섯 기준이 모두 같으면 **재경기**.)

→ 큐브 1개(+100)가 낙상 2번(−100)과 맞먹습니다. **욕심내다 넘어지면 손해.**

---

## 3. 경기 방식 (흐름)

맵 곳곳에 큐브가 흩어져 있습니다 — 평지, 박스언덕 위, 컨테이너(계단 위), 단상(경사로 위), 미로 구역(좁은 통로) 등 난이도가 다양합니다.

1. 당신의 **전략 텍스트**를 LLM(Gemini)이 읽습니다.
2. LLM 이 실시간으로 **다음에 노릴 큐브(우선순위)** 를 정합니다.
3. 로봇이 그 큐브로 이동 → 도착하면 자동 획득 → 다음 큐브로.
4. **차량 1대가 정해진 경로를 순환**합니다. 부딪치면 **−30 + 튕겨나감**(차는 멈추지 않음).
   → 차를 피하는 것도 *당신의 전략* 몫입니다 (시스템이 자동으로 피해주지 않음).
5. 180초가 끝나면 총점을 비교합니다.

## 4. ⚙️ 원리 — 한 줄 전략이 어떻게 로봇을 움직이나

당신이 쓴 전략 한 줄이 로봇 관절 움직임까지 되는 과정:

```
   당신의 전략 (자연어, ≤300자)
        │   예) "박스언덕 큐브 먼저, 차 도는 구역은 나중에"
        ▼
🧠 LLM (Gemini)          전략 해석 → 다음 목표 큐브 결정 (우선순위)
        ▼
🗺️ Path Planner          로봇 위치 + 목표 → 다음 waypoint(경로점) + 등반 단계
        ▼
🎮 Waypoint Controller   waypoint → 속도 명령 (전진 vx / 회전 wz)
        ▼
🦿 정책 = 당신의 PT       속도 명령 + 센서 관측 → 관절 토크 (실제 보행/등반)
        ▼
      로봇이 움직인다 → 큐브 획득
```

### 핵심 분업: "두뇌" 와 "몸"
- **두뇌 (LLM + 전략)** = *무엇을* 할지 — 어떤 큐브를, 어떤 순서로, 무엇을 피할지.
- **몸 (예선 PT 정책)** = *어떻게* 움직일지 — 걷기·등반·균형 (예선에서 학습한 능력).
- 둘이 합쳐져 경기 행동이 나옵니다.
  → **예선에서 잘 만든 로봇 + 본선에서 잘 짠 전략 = 강팀.**

### ⏱️ 중요한 제약 — LLM 은 "느립니다" (응답 ~2~3초)
실시간으로 차를 휙 피하는 건 **불가능**합니다. 그래서 전략은 *순간 반사*가 아니라
**큐브 우선순위·구역 선택 수준의 "계획"** 이어야 합니다
(예: "차가 도는 동쪽은 나중에", "가까운 평지부터").

## 5. 전략 작성 팁

- **가치 vs 거리 vs 위험을 저울질**: 가까운 쉬운 큐브부터? 멀어도 큐브가 몰린 곳?
  차 경로·낙상 위험이 큰 곳은 뒤로?
- **내 로봇 강점에 맞추기**: 예선에서 *속도형* 으로 키웠으면 평지 큐브 위주,
  *안정형* 이면 박스언덕·계단 위 큐브까지 노려볼 만.
- **LLM 이 할 수 있는 것**: 우선순위 결정, 위험 구역 *대략적* 회피.
  **못 하는 것**: 실시간 반사 회피, 1초 단위 미세 조종.
- 길게 쓰지 말고(≤300자) **명확한 우선순위**로.

> ⚠️ **금지:** 시스템을 조작·교란하려는 지시(프롬프트 인젝션 등),
> 욕설·차별·불쾌감을 주는 표현은 쓸 수 없습니다. 전략은 본인이 작성해야 합니다.

## 6. 🎓 무엇을 배우나

- **계층형(hierarchical) 로봇 제어**: 고수준 추론(LLM)과 저수준 학습 제어(RL 정책)가
  어떻게 결합되는지 — 현대 로보틱스·AI 의 핵심 구조를 직접 체험.
- **LLM 을 "플래너" 로 쓰기**: 자연어 의도를 구조화된 결정(우선순위)으로 바꾸는 과정.
  같은 로봇이라도 *전략(프롬프트)* 에 따라 전혀 다르게 움직입니다.
- **지연·불확실성 속 의사결정**: 실시간 반응이 안 되니 *계획 수준*에서 승부를 봐야 함 —
  실제 로봇·자율 시스템의 본질적 제약을 몸으로 이해.
- **트레이드오프 사고**: 욕심(가까운 큐브) vs 가치(먼 큐브 다수), 위험(차·낙상) vs 보상.
  그리고 *예선의 보상 설계* 가 본선 성능으로 이어지는 **하나의 파이프라인**임을 체감.
- 결국: **자연어 한 줄 → 학습된 정책의 관절 토크 → 로봇 행동** 으로 이어지는
  전체 흐름을 직접 설계하고 관찰하게 됩니다.
