## 4. 네 영역 산수와 반증 가설
2026-09-22 `tools/go2_reward_mechanism.py::spec_margin({'lin_vel_z_l2':-1.75})` 직접 계산: walk margin **0.1420**(stop_max .0155), climb 변화 **+.0129**, sway **-.0235**, push **-.0193**. 기존 A033 행동 고정 산수이며 행동·점수 예측이 아니다. 밀침은 네 방향 묶음이므로 ±y를 제외할 근거로 쓰지 않는다. A043에서 sway 산수의 악화와 실제 험지 옆걸음 개선이 엇갈린 사실을 우선한다.

- H1(개선 가설): 중간값에서 계단 진행 개선과 G2 보호를 함께 만족한다.
- H2(경쟁): 계단 이득이 사라지거나 G2 악화가 유지된다. 중간값=중간 성능 가설 반박.
- H3(경쟁): G2가 회복돼도 G3/G6 등 다른 보호축이 악화된다. 후보 승급 불가.
- H4(한계): 학습seed/궤적 의존. 같은 seed 결과만으로 일반 효과 확정 불가.
자료가 완결되면 성능 실패도 정보 획득이다. 자료 결측을 가설 반박으로 세지 않는다.

### 9-1. c2와 c3의 관계를 숫자로 사전등록한다

`B` = 비G2 가중 순이득(/70), `L` = G2 가중 손실(/70)로 둔다. A043 실측은 `B = 6.733`, `L = 4.637`, 순 `+2.096`이다.

- c2: `B - L >= 2.53`
- c3(flat): G2 시나리오 proxy 하락 `<= 0.054` → 가중 `<= 0.567`. 그리고 G2 각 case 생존 하락 `<= 0.0625`.
- 따라서 **c3를 충족하고(`L <= 0.567`) 비G2 순이득이 `B >= 3.097` (A043의 약 46%) 이상 남으면 c2도 충족한다.**

**정정.** 회수 분석의 초안은 "c3만 통과하면 c2는 따라온다"고 적었다. **틀렸다.** c3는 `L`의 상한만 정하고 `B`의 보존은 보장하지 않는다. G2는 이번 탐색의 핵심 병목이지만 c2를 대체하는 관문이 아니다. 위 문장처럼 **조건부**로만 성립한다.

**선형 절반 가설(§4 H2)의 사전등록 수치.** 이득·손실이 둘 다 절반이 되면 `B = 3.367`, `L = 2.318` → 순 **+1.048** 으로 c2에 **1.482 미달**이고, `L`도 한도 0.567을 **1.751 초과**해 **c3도 실패**한다. 선형 절반이면 두 관문 모두 실패다.

한계: G2 시나리오 proxy는 case 최솟값이므로 '선형 절반'은 최솟값에 대한 보간이 아니다. 이 숫자들은 결과를 볼 때 해석이 갈리지 않도록 **미리 못 박는 것**이지 성능 예측이 아니다.
