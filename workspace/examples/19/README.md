# 19강 · 생각하는 로봇

**느린 대뇌(LLM)** 가 내 전략을 읽고 3색 큐브(노랑·초록·빨강)를 **어떤 순서로** 갈지 정하고,
**빠른 소뇌(내 정책 `.pt`)** 이 그 순서대로 걸어서 방문하는 예제예요.

두 루프가 동시에 돌아요 — LLM은 느려서(몇 초) 백그라운드로 생각하고,
그동안 시뮬은 안 멈추고 계속 돌아가요. 이게 19강의 핵심이에요.

## 폴더 구성

```
19/
├── 19-1.py                           ← ✏️ 여기만 고쳐요 (전략 + 정책 + 두 루프)
├── robot_sim.py                      ← 제어·시뮬 (고치지 않아요)
├── 19-Q1.py ~ 19-Q3.py               ← 코드 실습하기 문항 (따로 돌려봐요)
├── my_test.pt                        ← 내 정책 (3챕터에서 만든 .pt)
└── assets/
    └── h1/
        ├── h1.usd                    ← 로봇 모델
        └── payloads/geometries.usd   ← 로봇 메시 (없으면 로봇이 바닥을 뚫고 떨어져요)
```

## 채우기

`19-1.py` 에서 두 줄만 바꾸면 돼요:

```python
STRATEGY = "노란 큐브부터, 그다음 초록, 마지막에 빨강 순서로 가줘"   # 전략 (자연어)
POLICY   = "my_test.pt"                                        # 내 정책 파일 이름
```

전략은 자유롭게 바꿔보세요 — LLM이 알아서 순서를 정해줘요:
- `"가까운 큐브부터 순서대로 가"`
- `"빨강 먼저 가고, 초록은 마지막에"`
- `"초록, 빨강, 노랑 순서로"`


> **왜 로컬 모델(올라마) 대신 Gemini?** 로컬 LLM은 Isaac Sim과 **같은 GPU**를 나눠 쓰다 스트리밍(NVENC 인코더)을 굶겨 화면이 끊길 수 있어요. 클라우드 Gemini는 로컬 GPU를 안 써서 렌더·스트림과 안 부딪혀요. (실제 본선 시스템도 Gemini를 써요.)

## 코드 실습하기

강의의 「코드 실습하기」 문항이에요. Isaac Sim 없이 **파이썬만으로** 돌아가니 편한 곳에서 실행하고, 나온 값을 강의 입력칸에 적어보세요.

| 파일 | 문항 | 무엇을 보나 |
|---|---|---|
| `19-Q1.py` | 🥚 기본 · 도착했는지 거리로 판정 | 출력된 거리 값 |
| `19-Q2.py` | 🐣 보통 · Gemini 실패 시 fallback | 출력된 남은 큐브 수 |
| `19-Q3.py` | 🐥 도전 · 공유 상태 꺼내오기 | 스왑 뒤 `target` 값 |

심화(안전망 검증)·탐구(어느 층의 발화인가)는 실행 중에 관찰하거나 로그를 읽는 문제라 파일이 없어요.

이 파일들은 `scripts/gen-examples.mjs` 가 강의에서 자동으로 뽑아내요. 손으로 고치면 다음 생성 때 덮어써져요.

## 실행

> ⚠ **`19-1.py` 는 Script Editor 에 붙여 넣지 마세요.** 17·18강 예제와 달라요.
> 같은 폴더의 `robot_sim.py` 를 가져다 쓰기 때문에, 그 폴더에서 아래 러너로 실행해야 해요.

내 정책 파일을 이 폴더에 두고:

```bash
cd /workspace/examples/19
/workspace/IsaacLab/isaaclab.sh -p 19-1.py
```

## 관전 (화면 보기)

스트리밍 접속에 시간이 걸려서, 로봇은 **처음 30초쯤 제자리에서 균형을 잡고 서 있다가**
LLM이 정한 순서대로 3색 큐브를 하나씩 방문해요. 콘솔에는 이렇게 떠요:

```
[대뇌] 🧠 "..." → 다음은 yellow  (방문함: 없음)
[소뇌] 🦿 출발 → yellow
[소뇌] ✅ 도착: yellow
...
[소뇌] 🎉 모든 큐브 방문 완료
```

## 안 보이거나 안 될 때 (문제 해결)

- **화면이 하얗게 나오고 아무것도 안 보여요**
  → 브라우저 **하드 새로고침**(Cmd/Ctrl+Shift+R) 후 **30초쯤 기다려** 보세요
    (스트림 접속 + 로봇이 균형 잡는 시간이에요). 콘솔에 `[robot_sim] 카메라: 조망 시점 설정 완료` 가
    떠야 정상이에요. (`robot_sim.py` 는 최신본이어야 해요 — 헤드리스 스트리밍용 RTX·카메라 설정이 들어있어요.)
- **`ModuleNotFoundError: No module named 'robot_sim'`** 에러가 나요
  → `19-1.py` 를 Script Editor 에 붙여 넣은 경우예요. Script Editor 는 코드를 임시 폴더로 복사해
    돌려서 옆에 있는 `robot_sim.py` 를 못 찾아요. 위 「실행」의 터미널 명령으로 돌리세요.
- **`FileNotFoundError: 정책 파일 ... 못 찾음`** 에러가 나요
  → `.pt` 파일을 이 폴더에 두고, `19-1.py` 의 `POLICY` 를 그 **파일명과 똑같이** 맞추세요.
- **`[대뇌] ⚠ Gemini 키를 못 찾았어요`** 가 떠요
  → `practice_key.bin` 을 이 폴더에 두세요. (없어도 기본 순서 노랑→초록→빨강 으로는 돌아가요.)
