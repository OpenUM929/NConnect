작업 ID GO2-P1-PREP-20260913. 문서/코드 읽기 기반 검토이며 서버 실행·원시 재채점은 하지 않았다.
대상 HTML: workspace/training/quadruped/exported/report.html (Pilot 계열, A017 대응 아님).
원 학습 report가 다른 형태로 추가 회수되면 포함 필드를 다시 확인한다. 모든 HTML에 대한 일반화가 아니다.

## 결론
현재 HTML은 **분석의 첫 요약 자료**이지 영상·시계열 telemetry·원 학습 로그의 대체물이 아니다.
필독의 목적은 자료 대조와 빠른 문제 선별이다. 보고서 내용을 반복하는 문서·수동 표는 줄일 수 있다.
원자료가 이미 있고 정책/조건/지문이 맞으면 재분석으로 재사용한다. 확인된 공백만 추가 측정한다.

## 이번 연구에 적용
1. G5 하강 실패는 평가에서 확인되지만 그 원인은 미확정. HTML의 '흔들림 허용' 문구로
   회전 벌점 강화부터 정하지 않는다. -0.06은 DEFERRED_HYPOTHESIS 유지.
2. 기존 A027 전체 정량을 report 확인을 이유로 다시 실행하지 않는다. 필요한 공백은
   원 학습 report 대응, 하강 동작 및 판독 가능한 시간축이다.
3. 기존 18case 정량+18영상+18영상동시계측은 아직 제안량이다. 먼저 기존 자료의 정책/조건을
   대조하고, 재사용분과 새 측정분을 case별로 나눈 뒤 수량을 동결한다. 무조건 전량 재측정하지 않는다.
4. 관찰만으로 구분 가능한 정지/발걸림과 정량 회전 인과 질문을 구분한다.
   wx/wy 새 계측은 회전 가설을 실제로 구분할 때만 추가 검토한다. 지표를 많이 모으는 것 자체는 목표가 아니다.
5. 별도 rollout 영상과 telemetry를 같은 사건처럼 연결하지 않는다. 원인 선후 주장은 같은
   rollout·env·시간 대응이 확인된 범위에서만 한다. 프레임 표본/영상은 힘·접촉을 직접 계측한 것과 다르다.

## 한계
HTML 생성기의 낙상률 계산 코드를 이번에 감사하지 않았다. 따라서13.8%의 정확한 분모/집계 구현은
본문 표기 이상의 확정이 아니다. 영상만으로 관절 힘·회전 원인까지 증명할 수 없고, telemetry만으로
실제 발걸림 장면을 확정할 수도 없다. 상호 보완 자료이며 어느 하나를 만능 근거로 승격하지 않는다.
