# H1 다음 학습 사전 예측 보고서 — `train_260828-03` (계획)

> **문서 역할:** Run 03을 실행하기 전에 변경값·예측·판정 기준을 고정한 내부 계획 문서다. 실행 결과나 최종 제출 적합성을 주장하지 않는다.

## 1. 변경 범위

| 항목 | Run 02 | Run 03 계획 |
|---|---:|---:|
| 변경 변수 | `termination_penalty=-50.0` | `termination_penalty=-100.0` |
| 나머지 reward 및 환경 | Run 02 설정 | 변경하지 않음 |
| seed / environments / iterations | 42 / 4,096 / 3,000 | 동일하게 유지 |

변경폭은 권장 범위 `-50 ~ -400` 안에서 `-50`의 2배 절댓값으로 정했다. `-400`으로 한 번에 이동하지 않아, 낙상 벌점 강화의 추가 효과와 부작용을 분리해 관찰한다.

## 2. 근거와 한계

Run 02에서 `termination_penalty=-50.0`은 Run 01 대비 마지막 `base_contact`를 0.9244에서 0.2979로 낮추고, `time_out`을 0.0756에서 0.7024로 높였다. 그러나 `error_vel_xy`는 0.3493에서 0.3596으로, `error_vel_yaw`는 0.2367에서 0.9341로 악화됐다.

따라서 `-100.0`은 **낙상률을 추가로 낮출 수 있다는 가설**을 검증하는 값이며, 최적값이라는 증거는 아직 없다. Run 02 영상 평가는 미완료이므로 실제 보행 품질·부들거림·회전 실패는 미측정이다.

## 3. 실행 전 사전 예측과 판정 기준

| 항목 | 사전 예측 | 판정 기준 |
|---|---|---|
| 낙상 종료 (`base_contact`) | 감소 또는 유지 | Run 02의 0.2979 미만이면 개선, 이상이면 미개선 |
| 시간 종료 (`time_out`) | 유지 또는 증가 | Run 02의 0.7024 이상 |
| terrain progression | 유지 또는 증가 | Run 02의 5.6356 이상 |
| 명령 추종 오차 | 추가 악화 위험 | `error_vel_xy`, `error_vel_yaw`를 Run 02와 함께 기록; 둘 다 악화하면 부작용으로 판정 |
| 실제 보행 | 미예측 확정 불가 | 동일한 1,000-step 영상에서 낙상·제자리 버티기·부들거림·불필요 회전을 별도 관찰 |

최고 `Train/mean_reward`는 termination penalty의 크기 자체가 달라 직접 비교가 왜곡될 수 있으므로, Run 03의 주 판정 지표로 사용하지 않는다.

## 4. 실행 상태
