**평가 미완료 — 영상 판정 보류.**

학습 지표는 `train_260828-04_add.md` §8에서 **PASS (학습 지표 기준)** 로 판정됐다. 그러나 §3의 채택 조건은 세 항목이며 세 번째("영상에서 제자리 회전이 사라져야 한다")가 미측정이다. **학습 지표 PASS를 근거로 Run 04를 채택 확정하거나 최종 제출 후보로 선언하지 않는다.**

Run 03에서 `error_vel_yaw = 1.7672`인 정책이 영상에서 "낙상 없이 제자리 좌회전"으로 나타난 전례가 있다. 학습 지표의 개선이 실제 보행 행동의 개선과 자동으로 일치하지 않는다는 뜻이므로, 영상 확인 전 판정을 확정하지 않는다.

## 4. 학습 지표가 시사하는 관찰 우선순위

영상 확인 시 다음을 우선 관찰한다. 아래는 [추론]이며 관찰을 대체하지 않는다.

1. **좌회전 소멸 여부** — `error_vel_yaw`가 0.9341 → 0.6230으로 개선됐고 `ang_vel_z` 명령 최대 절댓값(1.0 rad/s) 아래로 내려왔다. Run 03에서 관찰된 명령 무관 회전이 줄었을 가능성이 있다.
2. **직진 이동의 손해 여부** — `error_vel_xy`가 0.3596 → 0.4102로 +14.07% 악화했다. 회전은 좋아졌으나 전진이 굼떠졌을 가능성이 있다.
3. **낙상 빈도** — `base_contact = 0.3071`로 낙상률 30.7%다. 사전 기준(0.40)은 통과했으나 절대값은 높다.
4. **떨림·튐** — `Policy/mean_std = 1.4191`로 부작용 기준 1.45에 여유 0.031로 근접했고, `Episode_Reward/action_rate_l2`가 -0.0584 → -0.0698로 악화했다. 동작이 거칠어졌을 가능성이 있다.
