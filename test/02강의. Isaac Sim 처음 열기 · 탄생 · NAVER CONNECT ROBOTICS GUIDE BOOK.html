02. Isaac Sim 처음 열기

오늘의 목표는 단 하나, 공 하나를 시뮬레이션 환경에 가져와 보는 거예요. 앞으로 Isaac Sim에서 반복해서 쓰게 될 기본 패턴이 이번 강에 다 담겨 있어요.

①

생각 열기

여러분이 좋아하는 게임을 떠올려 보세요. 2단 점프가 가능한 게임이 있지 않나요? 우리의 로봇도 같은 게임 환경에서 연습할 수 있을까요?

같은 공, 다른 움직임

Isaac Sim은 엔비디아(그래픽카드로 유명한 GPU 제조사)가 만든 로봇 전용 시뮬레이션 환경이에요. 게임 엔진과 닮은 구석이 많아요. 게임 엔진도 Isaac Sim도 물리 법칙을 연산하고, 값도 바꿀 수 있죠. 진짜 차이는 목적이에요. 어느 쪽 공이 어떻게 움직일지 예상해보고 직접 눌러봐요.

게임 세계
재미 우선 · 중력도 반발(튕김)도 마음대로
실제 세계
현실 그대로 · 중력 -9.81 m/s², 반발 0.5
게임은 재미를 위해 물리 법칙을 자유롭게 비틀어도 돼요. 하지만 Isaac Sim은 로봇을 진짜 세상으로 내보내야 하니, 현실의 물리 법칙을 그대로 연산해요.중력 같은 기본값도 지구 환경에 맞춰져 있어요. 그래서 Isaac Sim 안에서 잘 걷도록 배운 로봇은 실제 세상에서도 잘 걸을 가능성이 커져요.이 흐름이 1강에서 본 sim-to-real이에요.

왜 Isaac Sim을 배울까

물리 법칙을 제대로 연산하는 시뮬레이터는 여럿 있어요. 그중 Isaac Sim을 고른 이유는 크게 세 가지예요.

REASON · 01

실전으로 이어지는 가상 훈련

  • 현실 그대로의 물리 법칙 중력과 충돌, 마찰을 실제와 똑같이 연산해요
  • sim-to-real 시뮬레이션 환경에서 학습시킨 로봇을 그대로 실제 세상으로 내보내요
  • 안전한 실패 실제 로봇은 한 번 떨어뜨리면 크게 고장 나지만, 시뮬레이션 환경에선 실패하고 넘어져도 괜찮아요

실제로 로봇이 부서지거나 고장나지 않으니, 마음껏 시도하고 넘어지며 배울 수 있어요.

REASON · 02

로봇 수천 대를 한 번에 훈련

  • GPU 연산 그래픽카드 한 장에 든 수천 개의 연산 코어가 로봇마다 계산을 나누어 맡아, 수천 대의 로봇을 동시에 시뮬레이션해요
  • 압도적 속도 실제 로봇 한 대가 1,000시간 동안 걸음마를 연습하려면 40일이 넘게 걸리는데, 시뮬레이터 속 수천 대의 가상 로봇을 동시에 학습시키면 단 몇 분 만에 끝낼 수 있어요
  • Replicator(데이터 합성 도구) 사물을 인식하는 인공지능(AI)을 학습시키려면 수많은 이미지 데이터가 필요해요. 빛, 색상, 물체 위치를 다채롭게 바꿔가며 학습용 이미지와 정답 데이터를 자동으로 만들어줘요

한 대씩 실험하던 걸 수천 대가 한꺼번에 반복하니, 학습 속도가 엄청나게 빨라져요.

REASON · 03

로봇 회사가 실제로 쓰는 도구와 코드

  • ROS(로봇 운영체제) Isaac Sim에서 짠 코드를 실제 로봇 제어에 그대로 옮겨 쓸 수 있어요
  • USD(범용 장면 표현) 픽사가 만든 3D 표준이라, 만들어 둔 로봇과 장면을 다른 프로그램에서도 그대로 열어 쓸 수 있어요
  • 현업 역량 여기서 배운 Isaac Sim 조작 방법과 파이썬 코드가 실무에서도 그대로 사용돼요

로봇을 만드는 회사들이 Isaac Sim, Isaac Lab을 다뤄본 사람을 찾고 있어, 이 경험이 그대로 포트폴리오 한 줄이 돼요.

팀 서버 접속하기

Isaac Sim은 성능 좋은 그래픽카드가 필요해서, 이번 대회에서는 미리 준비된 팀 서버에서 돌려요. 실습할 때 대회 보드에서 서버 시작하기 버튼을 누르면 Isaac Sim 화면이 열려요.

서버는 한 팀이 한 번에 하나씩, 팀에 주어진 시간만큼 쓸 수 있어요. 실습이 끝났다면 바로 종료해주세요.

Isaac Sim 화면 구성

화면에서 먼저 익힐 곳은 네 군데예요. 이 네 곳의 위치만 알아두면, 나머지 패널은 필요할 때 찾아 쓰면 돼요.

카메라 단축키 네 가지

뷰포트를 돌리고 옮기고, 확대하고 축소하는 카메라 단축키예요. 그중 F 키를 특히 자주 쓰게 돼요. macOS에서는 Alt 대신 ⌥ Option을 눌러요.

Alt+좌클릭 드래그
둘러보기(Orbit). 물체 주위를 빙 도는 회전이에요. 좌우로 끌면 옆에서, 위아래로 끌면 위나 아래에서 보게 돼요.
Alt+휠클릭 드래그
평행이동(Pan). 보는 각도는 그대로 두고 옆으로 움직여요.

확대와 축소(Zoom). 휠 스크롤은 빠르게, 드래그는 세밀하게 조절돼요.

코드로 장면을 만드는 Script Editor

마우스로 하나하나 만드는 대신, 파이썬 코드로 한 번에 세상을 다뤄요. Script Editor(스크립트 에디터)를 여는 법은 단순해요.

X, Y, Z 좌표 읽는 법

position=np.array([0, 0, 1.0])의 세 숫자는 순서대로 X(앞뒤), Y(좌우), Z(위아래)예요. np.array는 파이썬에서 좌표를 표현하는 방식 중 하나예요. 자세한 사용법은 뒤에서 다루니 걱정하지 않아도 돼요.

X, Y, Z 세 값으로 물체 위치 정하기
3D 불러오는 중…
물체 위치 (좌표)
position = [0.0, 0.0, 0.0]
Isaac Sim에선 이 세 값을 코드로 position=np.array([X, Y, Z])처럼 정해요.
X
앞뒤
양수면 앞, 음수면 뒤
Y
좌우
양수면 왼쪽, 음수면 오른쪽
Z

단위는 미터(m)예요. 1.0은 1m, 1.2는 1m 20cm죠. 이 책에 나오는 수치는 단위가 모두 같으니, 숫자를 그대로 미터 단위로 읽으면 돼요.

Z축이 위인 Z-up 좌표계

Isaac Sim은 Z축이 위쪽(Z-up)인 좌표계를 써요. 바닥을 XY 평면으로 깔고, 거기서 솟는 높이를 Z로 둬요. 2D 그래프에선 세로축 Y가 위였지만, 평면을 바닥에 눕히면 위였던 자리를 새 축 Z가 이어받죠. 학교에서 배우는 3D 공간좌표도 같은 Z-up이에요. Z가 높이라서, "로봇을 1m 공중에 띄운다"는 말은 곧 세 번째 숫자를 1.0으로 두는 거예요. position=[?, ?, 1.0]처럼요.

평면을 눕히면 생기는 Z축
3D 불러오는 중…
▶ 참고 Unity 계열 게임 엔진이 Y축을 위로 두는 이유
Unity 같은 게임 엔진은 Y축이 위(Y-up)예요. 게임은 원래 2D 화면에서 출발했거든요. 화면은 가로 X, 세로 Y로 그려요. 여기에 깊이 Z를 더해 3D로 넘어가면서, 화면의 세로였던 Y가 그대로 위쪽으로 굳었어요. 게임 엔진은 카메라가 보는 화면이 기준인 셈이죠. 반대로 로보틱스, CAD, 수학은 바닥(땅)에서 출발해요. 로봇은 바닥에 서서 키나 점프 높이처럼 높이를 자주 다루니, 그 높이를 Z로 두는 게 자연스러워요. 어느 쪽도 틀린 게 아니라 출발점이 다른 것뿐이에요. 3D 모델을 만드는 블렌더나, 게임 엔진인 언리얼도 Z-up을 써요. Isaac Sim도 겉모습은 게임 엔진과 닮았지만, 로봇을 위해 Z-up을 골랐어요.

직접 해보기

Isaac Sim의 Script Editor는 붙여넣기가 막히는 등 제한이 많아요. 그래서 보통은 편집이 편한 에디터를 함께 쓰죠. 우리는 서버에 연결된 VS Code에 코드를 저장하고, Isaac Sim에서 그 파일을 열어 실행해요. 새 파일을 만드는 건 이번 한 번이고, 다음 강부터는 test1.py를 다시 열어 써요. 아래 순서대로 따라 해봐요.

코드를 넣고 실행하기

보통 · color 값으로 색 바꾸기

내 답
정답은 하나가 아니에요. 초록 값에 0, 0.3, 0.6, 1.0을 한 번씩 넣어 ▶ Play로 공 색이 어떻게 변하는지 직접 확인해봐요.
정답 → 초록을 0.5 이상으로 올리면 노랗게 보여요. 1.0이면 가장 선명한 노랑([1.0, 1.0, 0.0])이에요.
1color의 가운데 칸이 초록이에요. 지금은 0.0이라 빨강만 켜져 있죠.
2초록을 0으로 두면 빨강 그대로, 올릴수록 노랑에 가까워져요.
3얼마나 올려야 노랗게 보일지, 값을 바꿔가며 눈으로 확인해봐요.

도전 · 바둑판 격자 채우기
이중 for 루프로 공을 격자 모양으로 띄워봐요
import omni.usd
import numpy as np
from isaacsim.core.api import World
from isaacsim.core.api.objects import DynamicSphere

if World.instance() is not None:
    World.instance().clear_instance()
omni.usd.get_context().new_stage()
world = World(stage_units_in_meters=1.0)
world.scene.add_default_ground_plane()

count = 0
for ix in range(3):
    for iy in range(3):
        world.scene.add(DynamicSphere(
            prim_path=f"/World/Ball_{ix}_{iy}", name=f"ball_{ix}_{iy}",
            position=np.array([ix * 0.5, iy * 0.5, 2.0]), radius=0.15))
        count += 1
world.reset()
print(f"격자에 만든 공 개수 = {count}")
이중 for 루프가 격자를 채워요. Script Editor에 뜬 총 공 개수를 입력해보세요.
내 답개
정답 → 9 (3 × 3). 이중 루프 한 번이면 격자가 채워져요.
1바깥 for와 안쪽 for를 중첩하면, 칸 수는 두 범위를 곱한 만큼이 돼요.
2prim_path와 name 모두 {ix}_{iy}를 넣어 충돌을 막아요.
3position을 [ix*0.5, iy*0.5, 2]로 두면 바둑판처럼 펼쳐져요.

심화 · 떨어지며 회전하는 큐브
큐브에 회전 속도를 줘서, 떨어지면서 빙글빙글 돌게 만들어요
import omni.usd
import numpy as np
from isaacsim.core.api import World
from isaacsim.core.api.objects import DynamicCuboid

if World.instance() is not None:
    World.instance().clear_instance()
omni.usd.get_context().new_stage()
world = World(stage_units_in_meters=1.0)
world.scene.add_default_ground_plane()

cube = world.scene.add(DynamicCuboid(
    prim_path="/World/Cube", name="cube",
    position=np.array([0, 0, 2.0]),
    scale=np.array([0.3, 0.3, 0.3]),
    color=np.array([0.2, 0.8, 0.2])))
world.reset()
cube.set_angular_velocity(np.array([0, 0, 5.0]))

for _ in range(120):
    world.step(render=False)
z = cube.get_world_pose()[0][2]
print(f"회전하며 떨어진 큐브 높이 Z = {z:.2f}")
큐브가 돌면서 떨어져요. Script Editor에 뜬 최종 높이 Z를 입력해보세요.
내 답m
정답 → 약 0.15 (한 변 0.3의 절반). 회전해도 결국 바닥에 닿아요.
1먼저 DynamicCuboid를 변수에 담아요. cube = world.scene.add(...)
2world.reset() 뒤에 cube.set_angular_velocity(...)로 회전 속도를 줘요.
3[0, 0, 5.0]은 Z축을 중심으로 도는 속도예요. 값을 키우면 더 빨리 돌아요.

탐구 · 여러 공을 리스트로 관리
만든 공들을 리스트에 모아두고, 나중에 위치를 한꺼번에 출력해요
import omni.usd
import numpy as np
from isaacsim.core.api import World
from isaacsim.core.api.objects import DynamicSphere

if World.instance() is not None:
    World.instance().clear_instance()
omni.usd.get_context().new_stage()
world = World(stage_units_in_meters=1.0)
world.scene.add_default_ground_plane()

balls = []
for i in range(3):
    b = world.scene.add(DynamicSphere(
        prim_path=f"/World/Ball_{i}", name=f"ball_{i}",
        position=np.array([i * 0.5 - 0.5, 0, 1.5]), radius=0.15))
    balls.append(b)
world.reset()

for b in balls:
    z = b.get_world_pose()[0][2]
    print(f"{b.name}: z = {z:.2f}")
print(f"리스트에 담긴 공 개수 = {len(balls)}")
공을 리스트에 모아 한꺼번에 위치를 출력해요. Script Editor에 뜬 리스트 공 개수를 입력해보세요.
내 답개
정답 → 3. for i in range(3)은 i가 0, 1, 2로 바뀌며 같은 코드를 3번 반복해요. 공이 100개여도 코드를 100번 쓰는 대신 range(100) 한 줄이면 되고, 만든 공을 balls 리스트에 모아두면 for b in balls로 전부 한꺼번에 다룰 수 있어요.
1빈 리스트 balls = []를 만들고, 루프에서 만든 공을 balls.append(b)로 모아요.
2나중에 for b in balls로 돌면서 get_world_pose()로 위치를 한꺼번에 출력해요.
3객체를 변수 하나에만 담지 말고 리스트로 모으면, 개수가 많아져도 한 번에 다룰 수 있어요.

2강 한눈에 정리

  • Isaac Sim은 게임 엔진과 달리 현실의 물리 법칙을 그대로 연산해요
  • 좌표는 X(앞뒤), Y(좌우), Z(위아래)로 읽고, 단위는 미터예요
  • Ctrl + Enter로 코드를 실행하면 공이 바로 떨어져요. ▶ Play와 ■ Stop으로 다시 보거나 멈춰요
  • 화면에서 물체를 놓쳤을 땐 F 키 하나면 바로 찾아와요
  • prim_path는 물체마다 하나뿐인 고유 주소라, 겹치지 않게 지어줘요
