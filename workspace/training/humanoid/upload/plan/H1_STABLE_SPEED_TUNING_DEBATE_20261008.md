## §3. 관측 사실과 원인 검토
사실:
1. Run06이 측정된 가장 높은 직진 명령은 0.75 m/s다. 이때 실제 평균은 0.744이고 낙상은 0이다. **0.75 초과 명령의 실제 속도·낙상은 미측정이다.** 그래서 "현재 속도의 상한"이 정의되어 있지 않다.
2. 평균 속도는 명령과 맞는다. 오차의 대부분은 매 스텝 흔들림이다. 특히 yaw는 2/3가 8 Hz 이상 성분이다.
3. 공식 점수는 명령 0인 시나리오까지 고르게 약 17% 깎였다. 평지에서는 낙상이 0이다.

원인 판단:
- 공식 감점의 주된 원인은 순간 속도 흔들림일 가능성이 높다(추정). 공식 생존·추종이 분리 제공되지 않아 확정할 수 없다.
- "더 빨리 가지 못한다"는 아직 원인으로도 약점으로도 확인되지 않았다. 1번 사실 때문이다.
- 설명되지 않는 것: 흔들림의 출처(관절 명령 떨림 vs 접지 충격 — 행동·관절 채널 미기록), H5가 가장 낮은 이유, 공식 추종 점수의 yaw 포함 여부.

감사 범위: 이 문서만 읽었다. 관측 근거는 §2의 수치로 한정하며, 다른 절의 인용은 제안 논리를 검토하는 데만 사용한다. 아래 새 문턱은 실측에서 도출한 최적값이 아니라 사전등록할 설계 제안이다.

1. **목표 해석 — 조건부 동의.** “안정적이면서 현재보다 높은 속도”를 높은 명령에서의 추종과 낙상 여부로 시험하는 것은 타당하다. 다만 §2의 0.75 명령·평균 속력 0.744·조기종료 0은 그 조건의 관측이지 현재 속도 상한이 아니다. 낙상 0도 평지 3 seed·672 에피소드의 관측 범위다. **수정 요구:** 사용자 목표의 성능 대조군은 Run06으로 고정한다. 전진 지표는 속력 크기가 아닌 명령 좌표계의 평균 vx/명령 vx로 정의하고, 제안 허용 구간은 0.95~1.05로 둔다. 낙상 0과 함께 xy·yaw 추종 비열등을 요구한다. “평지 H1~H7”은 H5 요철·H6 경사를 포함하므로 “H1~H7 각 지정 환경”으로 고친다.

2. **원인 판단 — 일부 반대.** H4 yaw의 8 Hz 이상 비율 68%/64%, 평균 바이어스 -0.039/+0.015와 RMSE 0.151/0.155는 해당 조건에서 평균 편차 외의 변동이 크다는 설명을 지지한다. 그러나 이 비율은 오차 크기나 공식 감점 기여율이 아니다. 공식 득점률 0.790~0.831과 별도 내부 평가의 낙상 0만으로 “공식 감점의 주된 원인”을 정할 수 없다. 추정이라는 표지만으로 그 우선순위가 정당화되지는 않는다. **수정 요구:** “H4 yaw 고주파 변동은 내부 추종 오차의 한 특징이며 공식 감점 원인은 미확정”으로 좁힌다. H4 결과를 H1~H7 전체 흔들림으로 일반화하지 않는다. 학습 낙상률 25.1%와 평지 672 에피소드 낙상 0도 서로 다른 분포로 분리한다.

3. **P0 선행 — 동의.** §2에는 직진 0.75 초과 실측이 없고, 학습 명령 상한 1.5는 실행 성능의 증거가 아니다. 현재 정책으로 목표를 이미 만족하는지 확인해야 한다. **수정 요구:** 제안한 평지 0.75/1.0/1.25, 요철 0.75/1.0, 복합 vx 1.0·wz ±0.5를 Run06·Run05에 동일 적용한다. 복합 vy는 0으로 명시하고, 두 정책에 같은 3개 평가 seed·각 32 env×20초를 사용한다. “현재 속도” 대신 환경별 “검증된 최고 시험 명령”으로 보고한다. 평지 1.25까지 만족하면 상한 미확정으로 표기하고, 더 빠른 목표를 미리 정하지 않은 상태에서 P1을 자동 실행하지 않는다. 실패 시에도 바로 학습값을 고르지 말고 전진 부족·yaw 악화·낙상을 구분한다.

4. **A 고정 1순위, B 조건부 2순위 — 반대.** §2의 H2는 0.75에서 평균 속력 0.744로 약 0.992이며, H4 vx 평균도 0.503/0.506으로 명령 0.50에 가깝다. 현재 자료에는 속도 항 강화가 필요한 평균 전진 부족이 확인되지 않았다. 반대로 yaw 고주파 비율만으로 행동 명령 떨림을 확정할 수도 없어 B를 자동 1순위로 뒤집는 것도 부적절하다. **수정 요구:** P0에서 높은 명령의 평균 vx 비율이 0.95 미만이고 낙상 0·yaw 비열등이면 A를 우선 탐색한다. 평균 vx 비율이 0.95~1.05인데 yaw 변동이 비열등 조건을 벗어나면 B를 우선 검토한다. 모두 만족하면 Run06 유지가 우선이다. 속도 부족과 낙상이 함께 나타나면 그 결과만으로 A 강화 또는 B 강화를 자동 선택하지 않는다.

5. **값·대조군·문턱 — 현안 반대.** §2는 Run06의 10,000 iter·seed 42·lin 1.0만 제시한다. Run05의 설정·성능 수치가 없어 “Run05 설정에서 한 줄 변경”의 기준값과 보존할 성능을 이 문서만으로 확인할 수 없다. 1.5가 2.0보다 작거나 미시험이라는 이유는 안전성 근거가 아니며, 같은 +0.5도 상대 증가는 0.5→1.0의 100%와 1.0→1.5의 50%로 다르다. **수정 요구:** 1.5는 P0의 A 선택 조건을 만족할 때만 +50% 탐색값으로 명시한다. 3,000 iter·seed 42는 짧은 탐색으로 허용하되 신규 학습인지 checkpoint 재개인지 고정한다. 효과 비교에는 동일 시작 방식·학습 예산·seed의 lin 1.0 대조군을 쓰고, 목표 성능 채택에는 Run06을 별도 대조군으로 유지한다. Run05가 이 조건에 맞는다는 정보가 없으면 효과 비교는 INCONCLUSIVE다.

   **판정 수정안:** 속도 개선은 환경별 시험 격자에서 검증 명령이 Run06보다 최소 0.25 m/s 높아지는 것으로 정한다. 같은 시험 조건·같은 시간 구간에서 낙상 0, 각 case의 xy·yaw RMSE가 Run06 대비 5% 이내 증가여야 한다. §2 기준 예로 H2 xy 0.097→상한 0.10185, H4 좌/우 yaw 0.156/0.157→상한 0.1638/0.16485다. 이 값은 P0 재평가 전의 예시이며 재평가 기준값과 5% 허용폭을 학습 전에 고정한다. H4 분해표의 2초 이후 RMSE 0.151/0.155와 전체 평가 RMSE를 혼용하지 않는다. +20%는 비열등 허용폭이 아니라 별도 강한 악화 표식으로만 쓰고, +5~20%도 채택하지 않는다. “평가 sd 2배”는 단위·추정 단위가 불명확하고 분산이 클수록 허용폭이 커지므로 삭제한다. 3개 평가 seed에서 조건을 모두 만족하면 탐색상 채택 검토, seed별 결론이 갈리면 INCONCLUSIVE로 둔다. 8 Hz 비율은 단독 채택 문턱에서 제외하고 총 yaw RMSE와 함께 진단값으로 보고한다. 단일 학습 seed의 결과로 10,000 iter에 자동 승급하지 말고 동일 대조 설계의 독립 학습 seed 1개를 추가 확인한다.

6. **경쟁 가설·반례 누락 — 동의.** ① Run06이 1.0/1.25도 이미 추종할 수 있다는 가설은 0.75 초과 미측정 때문에 열려 있다. ② H4의 전진 평균은 이미 맞고 yaw 변동이 크므로 전진 보상 강화가 표적과 어긋날 수 있다. ③ 8 Hz 이상 비율은 다른 주파수 성분이 커져도 낮아질 수 있어 비율 감소만으로 안정 개선을 판정하면 안 된다. ④ 학습 지형 66%가 계단·박스이고 학습 낙상률은 25.1%이므로 평지 낙상 0과 학습 안정성을 같은 결론으로 묶을 수 없다. ⑤ Run06의 10,000 iter와 제안 후보의 3,000 iter 차이는 보상 효과와 학습 길이 효과를 혼동시킬 수 있다. **수정 요구:** 이 다섯 가지를 사전등록한다. A 뒤 B를 시험할 경우 A+B 대 A가 직접 효과 비교이고 Run06은 최종 성능 대조임을 분리한다. 낙상 증가 뒤 1.25로 낮추는 분기는 자동 실행하지 않는다. 1.25가 안전하다는 근거는 §2에 없으므로 새 관측과 경쟁 설명으로 다시 선택한다.

판정: 측정 선행에는 동의하나, A의 고정 우선순위·Run05 중심 채택 기준·불명확한 비열등 문턱·자동 장기 승급은 수정이 필요하다. 사용자 목표를 다시 물을 사안은 아니다.

VERDICT: REVISE

## §11. Astra 감사 (2/3)

감사 범위: 지정된 이 문서만 읽고 §9의 요구와 §10의 반영 여부를 대조했다. 다른 원자료는 열지 않았다. §10의 Run05 설정·이력 보충은 문서 내 진술이며 원자료 검증 완료로 취급하지 않는다. 이번 판정은 요구 반영 여부에 한정한다.

결론: 주요 수정은 반영했으나 “빠짐없이 반영”하지는 않았다. 새로운 실험이나 사용자 목표 재확인 없이 아래 문구를 보완하면 된다.

| §9 요구 | §10 반영 여부 |
|---|---|
| 1. Run06 성능 대조, 명령 좌표계 vx 비율 0.95~1.05, 낙상 0과 xy·yaw 비열등, 지정 환경 구분 | 부분 반영. 대조·좌표·구간·환경 및 P1 추종 조건은 반영했지만 P0 검증·유지 조건과의 연결이 불완전하다 |
| 2. 공식 감점 원인 미확정, H4 관측 범위 제한, 학습·평가 분포 분리 | 반영. 분포 분리는 경쟁 가설 ④의 명시적 참조로 수용했다 |
| 3. 동일 격자·3 seed·32 env×20초, 상한 미확정, 자동 학습 금지, 실패 구분 | 대체로 반영. P0 비열등의 비교 기준과 “모두 만족”의 범위를 명확히 해야 한다 |
| 4. A 고정 우선순위 철회, 관측별 A/B 검토, 유지 및 복합 실패 분기 | 부분 반영. B의 “우선 검토”가 특정 값의 “탐색”으로 바뀌었다 |
| 5. +50% 탐색값, 시작 방식·예산·seed, 효과/성능 대조, 판정 문턱·시간 구간, 독립 seed의 동일 대조 설계 | 부분 반영. 주요 수치와 대조 역할은 반영했지만 판정 시간 구간과 독립 seed의 대응 대조 설계가 빠졌다 |
| 6. 경쟁 가설 ①~⑤, A+B 대 A, 낙상 후 1.25 자동 실행 삭제 | 반영. 다섯 가설은 명시적으로 참조했으므로 반복 기재할 필요가 없다 |

남은 수정 요구:

1. **P0의 검증·유지 조건을 완결한다.** “검증된 최고 시험 명령”은 vx 비율과 낙상만으로 정의되어 있다. §9-1의 xy·yaw 비열등을 포함하거나, 이 지표는 부분 지표이며 유지·채택에는 별도로 추종 비열등을 적용한다고 명시한다. P0 분기의 “yaw 비열등”에는 비교 정책·명령·환경·seed·시간 구간·허용폭을 고정한다. P1용 “Run06 P0 재측정값 대비 +5%”만으로 Run06 자체의 P0 분기 기준이 정의되지는 않는다. 유지 분기의 “모두 만족”에는 복합 좌·우회전도 포함한다고 명시한다.

2. **동일 평가 조건과 판정 구간을 고정한다.** §9-5는 같은 시험 조건·같은 시간 구간을 요구했다. 전 구간과 2초 이후 값을 나누어 보고하는 것만으로 어느 구간에 +5% 문턱을 적용하는지 정해지지 않는다. 후보·효과 대조군·Run06을 동일 환경·명령·평가 seed·길이·판정 구간으로 비교하고, 해당 구간은 학습 전에 고정한다고 명시한다. P1에서도 P0 격자와 H1~H7 각 지정 환경을 모두 재평가한다는 §7의 범위를 수정 정책에 연결한다. 고속 격자만으로 H1~H7 조건을 대신하지 않는다.

3. **독립 학습 seed에도 동일 효과 대조 설계를 적용한다.** §9-5의 “동일 대조 설계”가 §10에서는 빠졌다. 추가 seed에서도 후보와 lin 1.0 대조군의 시작 방식·3,000 iter 예산·학습 seed·checkpoint 선택 규칙을 맞춘다고 명시한다. 기존 seed 42 Run05만으로 추가 seed 후보의 보상 효과를 분리하지 않는다. 대응 대조가 없으면 효과 비교는 INCONCLUSIVE이며 Run06과의 목표 성능 비교와 구분한다. best checkpoint는 이름만 맞추는 것이 아니라 동일 선택 규칙을 사전에 고정한다는 뜻으로 명확히 한다.

4. **B의 검토와 값 확정을 구분한다.** §9-4는 yaw 변동만으로 행동 명령 떨림을 확정할 수 없으므로 B를 “우선 검토”하라고 요구했다. §10의 “-0.002 탐색”은 확정된 다음 실험이 아니라 검토 후보로 표기한다. P0 관측과 굼뜸·접지 충격 경쟁 설명을 대조하여 방향·변경 폭을 선택한다는 조건을 붙인다. 이는 새 승인 절차가 아니라 기존 조건부 선택 요구의 보존이다.
