## 전체 항의 누락 방지
10개 활성 항 모두 읽었다. track_lin/lin_vel_z는 기존 반례와 종료 결정 유지; ang/feet/action은 기존 진단 한계 유지; track_ang는 yaw 문제와 저고도 문제의 직접 연결 부족; flat_orientation은 각도이지 높이가 아니며 A047 반례; dof_pos_limits는 가중치0이라 rew=0으로 관절 한계 위반 없음 판정 불가. 비활성 undesired_contacts·없는 termination_penalty를 이름만 추가해 해결할 수 있다고 하지 않는다. 새 높이 보상 구현은 배포 코드 수정이 필요하므로 이번 가중치 후보와 구분한다.
