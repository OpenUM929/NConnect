# A052 명령 반복 반전 — 정책 §8의 측정 가능 범위와 기술 비교

## 질문과 출처
강좌 Go2 표의 명령 급변 억제, 배포 Go2 주석의 다리 떨림 설명이 현재 실패와 연결되는가.
코드 `action_reversal_analysis.py`, 출력 `ACTION_REVERSAL_COMPARISON.json`.
입력은 A052 rough_lateral seed202의 diag.csv.gz·steps.csv 및 기존 readout/EVENTS_DIAG.csv다.
모집단은 실패8·생존24. 기존 사건 T 기준 초기[1,3), 중간[T-3,T-1), 마지막[max(.5,T-1),T). 초기/중간은 T>=4만 사용한다. env25는 초기화 제외 후 빈 구간으로 남기며 삭제하지 않는다.

## 확인된 측정 한계
- A052 diag_meta.json의 fields와 go2_eval_diag.py의 출력 필드에 관절 위치·속도·가속도 개별 열이 없다. action·prev_action과 가중 가속도 비용은 있지만 실제 관절의 왕복 동작을 복원할 수 없다.
- go2_eval_telemetry_diag_wrapper.py:41-43은 evaluator_step 뒤 recorder.record를 부른다. action과 물리 상태는 같은 20ms 행에 저장된다. 센서 update_period는 5ms이나 전체 진단 로그가 그 substep을 모두 저장하지 않는다.
- 같은 행의 선후는 미식별이다. 다른 행의 시간 순서도 물리적 인과 확정이 아니다. reset 행은 제외한다.
- 따라서 이전 정책의 “관절 시간열을 읽는다”는 표현은 실제 채널 범위를 넘었다. 정책을 정정했다.

## 반전 지표의 의미
각 action 성분의 delta=action-prev_action에 대해 이웃 delta의 곱이 음수인 비율을 구한다. 분모는 연속 행 쌍 수×12다. 정확히 0이면 반전으로 세지 않는다. 별도 진폭 cutoff를 두지 않았다.
진폭은 모든 성분·행쌍에 대한 delta RMS와, 반전 성분만 제곱값을 남긴 RMS를 함께 기록한다. 후자는 반전 사례만으로 나눈 조건부 RMS가 아니다.
이 지표는 명령의 반복 반전이지 “다리 떨림” 검출기가 아니다. 정상 보행, 작은 수치 변화, 큰 교정 명령이 섞인다. 고주파 떨림 주파수나 실제 관절 진동을 판정하지 않는다.
동일 시각의 생존24대를 각각 집계해 중앙값으로 비교한다. 지형/보행 위상 매칭이 아니며 같은 생존군을 재사용하므로 독립 표본 검정으로 해석하지 않는다.

## 관측
- env2 초기 반전 비율 0.488, 대조0.509. 마지막은 0.374, 대조0.519. 마지막 전체 delta RMS는 0.629 대0.323으로 커진다.
- env27 초기 반전 비율 0.492, 대조0.509. 마지막은 0.417, 대조0.505. 마지막 전체 delta RMS는 0.456 대0.339다.
- env23 마지막 반전 비율은 0.526 대0.519지만 전체 delta RMS는 0.291 대0.330으로 작다.
- 따라서 명령 변화 비용 증가를 “짧은 주기로 더 자주 반전하는 떨림 증가”로 곧장 바꿀 수 없다. 반전의 빈도와 진폭은 다르다. 이 세 예만으로 다른 개체의 떨림 부재를 주장하지 않는다. 전 개체 창의 값은 JSON에 공개했다.
