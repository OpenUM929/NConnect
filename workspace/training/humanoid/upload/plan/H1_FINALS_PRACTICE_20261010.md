# 본선 규정 기반 H1 예상 연습 — 실행 사양

사용자 요청: 규정 기반 예상 환경에서 가장 높은 점수의 2족 정책과 LLM 전략을 시험한다.

## 기준과 완료 조건
- 공식 원문: https://robotics.connect.or.kr/rules/finals_regulations.html (v1.1, 2026-09-18 개정; 2026-10-10 직접 조회).
- 제4~7조: 공동 맵의 양팀, 180초, 일반 큐브100/박스언덕150, 낙상-50/차량충돌-30. 제9조 동점 순서 적용.
- 제5·10조: 실제 경로·속도·판정·Gemini는 운영진 제공. 참가자가 교체하는 것은 PT와300자 전략. 이번 별도 로컬 환경은 공식 엔진을 대체하지 않는다.
- H1: 최신 유지 후보 Run06 iter9900(총10000). 내부 독립 proxy65.73/70. 공식57.45 기록과 외부 제출 identity는 미확정이므로 '공식 최고점 정책'으로 단정하지 않는다.
- 원 report 직접 읽음: `workspace/_keep/train_260831-06_run05cfg_10000/final/report.html`, 19관절/9900/총10000,2026-08-31 10:26~12:28, 2시간2분. checkpoint SHA `8eb06e2b0f590077fe3d20557da3f77d5c7dc34a0507edfa3e4af8df8ff4b636`; JIT 정책 tensor 대응은 기존8/8 검증을 재사용하고 이번 실행에서 SHA도 남긴다. REPORT_READ_STATUS=READ_MATCHED.
- 완료: 180초 물리 rollout, map/가정·policy/source SHA·step CSV·점수event·원영상·프롬프트/실제LLM 응답 또는 명시적 접속실패를 보존. 점수 재계산·영상decode 확인. 실행 성공만으로 전략 최고점/공식 성능을 주장하지 않는다.

## 연습용 가정
- 24×20m, 11큐브, .5m grid. 평지·박스언덕·계단·경사·미로·차량 순환 구역. 모든 치수·배치/차속·획득반경/판정·복구는 가정이다.
- 원 H1 task가 지정하는 학습용 `h1_minimal.usd` URI와 기본 variant를 그대로 사용한다. 강좌용 별도 H1 asset을 사용한 초기 실행은 adapter 불일치로 제외했다. 정책 관측·actuator/action은 기존 H1 task를 재사용하고, `env.reset()` 후 실행한다. checkpoint/JIT actor tensor 8/8 일치를 이번 작업에서 다시 확인했다.
- 기본 Planner는 미검증 등반을 배제하고 평지/미로/차량구역의 도달가능 목표만 제시한다. 이는 H1이 등반 불가하다는 판정이 아니다. 고지 큐브 보너스·실제등반 성능 검증은 이번 기본 프로파일의 범위 밖이다.
- 차량은 이동하는 시각물·footprint접촉판정/속도knockback 대체기다. 공식 접촉물리와 동일하지 않다.
- torso_contact 종료 시 시작점복귀·3초 대기. 큐브는 수평 .6m·높이 .35m 판정. 같은tick 동시 도착은 거리 우선·정확동률 seed 교대.
- 상대도 같은 H1 정책이고 가장가까운 도달가능 큐브 선택. 실제 상대팀 전략·정책을 재현하지 않는다.
- 비교 대상 구현: nearest / flat_safe / score_rate. 세 전략 전체의 물리 비교는 아직 수행하지 않았다. 이번 180초 실행은 실제 Gemini 선택 대 nearest이며 시작 위치도 다르므로 전략 우열을 확정하지 않는다. score_rate는 탐욕적 점수/거리 대체기이며 확률적 기대총점 최적화가 아니다.
- 각 Gemini 선택 전 2.5초의 시뮬레이션 대기를 적용하며 네트워크 요청 중에는 물리를 일시 정지한다. 공식 지연 구현은 미공개다. 도달 가능한 목표가 없으면 대기하며 다른 선택기로 몰래 대체하지 않는다.
- 실제 Gemini 연결은 강좌 예제의 제공 연습키·동일모델을 이용한다. 공식 경기의 system prompt·관측범위·Planner와 동일하지 않다. 호출불가 시 rule기반 결과를 Gemini결과로 바꾸지 않는다.

## 사전등록 판정
- ARTIFACT_VERIFIED: 요청시간 CSV행수·model SHA·event점수일치·영상decode. VIDEO_OBSERVED 여부는 내용 관찰 후 별도 기록.
- INTERNAL 연습 점수: 일반×100+언덕×150-낙상×50-충돌×30. 공식 OFFICIAL_RESULT가 아니다.
- 후보전략은 동일조건 상대 대비 획득점수/낙상/충돌/시간을 함께 비교한다. 한map·한seed의 최고는 exploratory이며 맵전체/공식경기 최고를 뜻하지 않는다.
- 초기화·형상·프롬프트접속 실패는 score0이 아니라 실행미완료로 기록. partial은180초 점수와 비교하지 않는다.
- H1~H7 예선 평가 재실행 없음. 본선 자유이동·회전·미로 경로 수행만 직접 측정; 고지·밀침복구를 이 결과로 승격하지 않는다.
