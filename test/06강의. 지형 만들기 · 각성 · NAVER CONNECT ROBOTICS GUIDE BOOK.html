06. 지형 만들기

5강까지 로봇의 관절을 움직여봤어요. 이제 로봇이 걸어갈 바닥을 깔아줄 차례예요. 어떤 지형(Terrain)을 만들면 좋을까요? 블록을 배치하고 높낮이를 조절하며 로봇이 훈련할 나만의 지형을 빚어봐요.

Dynamic과 Fixed의 차이

장면이 밝아졌으니 이제 그 위에 놓을 블록을 골라봐요. 2~3강에서 쓴 DynamicSphere, DynamicCuboid는 물리 법칙을 따르는 물체예요. 떨어지고 튕기고 굴러다녀요. 지형 블록은 로봇이 밟을 때마다 밀리면 안 되니까, FixedCuboid를 사용해야 해요.

Dynamic 블록과 Fixed 블록 위에 로봇 세우기
Dynamic · DynamicCuboid
Fixed · FixedCuboid
어느 블록이 로봇을 버텨줄까요?
두 클래스를 헷갈리면 로봇이 블록을 밟는 순간 블록이 주르륵 밀려나며 지형이 통째로 무너져요. 그러니 지형에는 Fixed로 시작하는 클래스를 꼭 쓰도록 해요.

표면 성질을 정하는 friction, restitution, density

블록의 모양만큼 중요한 게 표면 성질이에요. 같은 평지여도 빙판과 카펫은 걸을 때 느낌이 아주 달라요. 시뮬레이션 환경도 똑같아요. 코드에선 아래 세 가지 값을 정해줘요.이 값들은 PhysicsMaterial이라는 재질 하나에 묶어 두고, 블록을 만들 때 physics_material=로 입혀요. 재질 하나를 만들어 블록 수백 개에 같이 입힐 수 있어요.

friction

마찰

0에 가까우면 빙판, 1 이상이면 고무처럼 까끌해져요.
너무 낮으면 로봇이 발을 디딜 때마다 미끄러져요.
실제로는 정지 마찰과 운동 마찰 둘로 나뉘어요.

restitution

반발

0이면 떨어진 자리에서 튕기지 않고 그대로 멈추고,
1에 가까우면 공처럼 통통 튕겨요.
지형은 0이나 0에 가까운 값이 자연스러워요.

density

밀도

단위는 kg/m³예요.
FixedCuboid는 움직이지 않아 큰 영향이 없지만,
DynamicCuboid는 이 값으로 무게가 정해져요.

조건을 바꿔가며 배우는 도메인 랜덤화

같은 지형에 friction만 0.3 → 1.2로 바꿔도 학습 결과가 달라져요. 여기서 도메인은 로봇이 놓인 환경을 말해요. 바닥의 마찰, 바닥의 높낮이, 로봇의 무게처럼 로봇을 둘러싼 조건을 통틀어 도메인이라고 하죠. 도메인 랜덤화(Domain Randomization)는 시뮬레이션 속 환경 조건을 매번 살짝씩 바꾸는 거예요. 현실은 매번 조건이 달라지니까, 그 변화에도 로봇이 유연하게 적응하도록 만드는 거죠.

이렇게 여러 조건을 겪은 로봇은 처음 보는 환경에도 잘 적응해요. 바닥마다 다른 마찰과 높낮이를 겪는 동안, 로봇은 특정 바닥에만 맞는 걸음이 아니라 어느 바닥에서나 통하는 걸음을 찾아내거든요. 이처럼 훈련할 때 겪어보지 못한 새로운 환경에서도 원래 걷는 실력을 안정적으로 유지하는 능력을 일반화라고 해요.

import omni.usd
import numpy as np
import random
from isaacsim.core.api import World
from isaacsim.core.api.objects import FixedCuboid

if World.instance() is not None:
    World.instance().clear_instance()
omni.usd.get_context().new_stage()
world = World(stage_units_in_meters=1.0)
world.scene.add_default_ground_plane()

count = 0
def build_terrain(start_x=1.5, forward=20, sides=10, cell=0.5, min_h=0.02, max_h=0.20):
    global count
    for i in range(forward):
        for j in range(sides):
            h = random.uniform(min_h, max_h)
            x = start_x + i * cell
            y = (j - (sides - 1) / 2) * cell
            world.scene.add(FixedCuboid(
                prim_path=f"/World/Terrain/block_{i}_{j}",
                name=f"block_{i}_{j}",
                position=np.array([x, y, h / 2]),
                scale=np.array([cell, cell, h])))
            count += 1

build_terrain(start_x=1.5, forward=40, sides=10)

import asyncio
async def run():
    await world.reset_async()
    print(f"깔린 지형 블록 수 = {count}")

asyncio.ensure_future(run())

import omni.usd
import numpy as np
import random
from isaacsim.core.api import World
from isaacsim.core.api.objects import FixedCuboid

if World.instance() is not None:
    World.instance().clear_instance()
omni.usd.get_context().new_stage()
world = World(stage_units_in_meters=1.0)
world.scene.add_default_ground_plane()

count = 0
x_min = None
x_max = None
def build_terrain(start_x=1.5, forward=20, sides=10, cell=0.5, min_h=0.02, max_h=0.20):
    global count, x_min, x_max
    for i in range(forward):
        for j in range(sides):
            h = random.uniform(min_h, max_h)
            x = start_x + i * cell
            y = (j - (sides - 1) / 2) * cell
            world.scene.add(FixedCuboid(
                prim_path=f"/World/Terrain/block_{i}_{j}",
                name=f"block_{i}_{j}",
                position=np.array([x, y, h / 2]),
                scale=np.array([cell, cell, h])))
            count += 1
            front = x - cell / 2
            back = x + cell / 2
            x_min = front if x_min is None else min(x_min, front)
            x_max = back if x_max is None else max(x_max, back)

build_terrain(forward=30, sides=15, cell=0.2, max_h=0.08)

import asyncio
async def run():
    await world.reset_async()
    print(f"자갈밭 블록 수 = {count}")
    print(f"지형 앞뒤 길이 = {x_max - x_min:.2f} m")

asyncio.ensure_future(run())

2지형 길이는 블록 한 칸의 크기와 앞으로 놓은 칸 수, 둘이 함께 정해요.
3블록이 촘촘할수록 같은 길이에 블록이 많이 들어가고, 그만큼 시뮬레이션도 무거워져요.

if World.instance() is not None:
    World.instance().clear_instance()

world.scene.add_default_ground_plane()

stage = omni.usd.get_context().get_stage()
sun = UsdLux.DistantLight.Define(stage, "/World/Sun")
sun.CreateIntensityAttr(3000.0)

rough = PhysicsMaterial(prim_path="/World/rough_material",
                        static_friction=1.10, dynamic_friction=0.80, restitution=0.0)

count = 0
for i in range(18):
    for j in range(10):
        h = random.uniform(0.05, 0.25)
        x = 1.5 + i * 0.5
        y = (j - 4.5) * 0.5
        world.scene.add(FixedCuboid(
            prim_path=f"/World/Terrain/block_{i}_{j}",
            name=f"block_{i}_{j}",
            position=np.array([x, y, h / 2]),
            scale=np.array([0.5, 0.5, h]),
            physics_material=rough))
        count += 1
import asyncio

    print(f"마찰을 입힌 지형 블록 수 = {count}")
    print(f"정지 마찰 = {rough.get_static_friction():.2f}")
    print(f"운동 마찰 = {rough.get_dynamic_friction():.2f}")

asyncio.ensure_future(run())

탐구 · 구간마다 달라지는 블록 밀도
평지 → 촘촘한 자갈밭 → 높은 지형 → 험한 구간, 네 구간을 늘어놓고 구간마다 길이와 블록 수를 비교해봐요
import omni.usd
import numpy as np
import random
from isaacsim.core.api import World
from isaacsim.core.api.objects import FixedCuboid

if World.instance() is not None:
    World.instance().clear_instance()
omni.usd.get_context().new_stage()
world = World(stage_units_in_meters=1.0)
world.scene.add_default_ground_plane()

sections = []
def build_terrain(label, start_x=1.5, forward=20, sides=10, cell=0.5, min_h=0.02, max_h=0.20):
    n = 0
    for i in range(forward):
        for j in range(sides):
            h = random.uniform(min_h, max_h)
            x = start_x + i * cell
            y = (j - (sides - 1) / 2) * cell
            world.scene.add(FixedCuboid(
                prim_path=f"/World/Terrain_{int(start_x)}/block_{i}_{j}",
                name=f"block_{int(start_x)}_{i}_{j}",
                position=np.array([x, y, h / 2]),
                scale=np.array([cell, cell, h])))
            n += 1
    sections.append((label, forward * cell, n))

build_terrain("평지", start_x=1.5, forward=10, min_h=0.02, max_h=0.02)
build_terrain("자갈밭", start_x=7.5, forward=20, cell=0.2, max_h=0.08)
build_terrain("높은 지형", start_x=12.5, forward=10, min_h=0.05, max_h=0.32)
build_terrain("험한 구간", start_x=17.5, forward=10, min_h=0.02, max_h=0.5)
import asyncio
async def run():
    await world.reset_async()
    for label, length, n in sections:
        print(f"{label}: 길이 {length:.1f} m, 블록 {n}개")

asyncio.ensure_future(run())
출력에 네 구간이 한 줄씩 찍혀요. 자갈밭 구간의 블록 수는 평지 구간의 몇 배인가요?
내 답배
정답 → 2배. (평지 5.0 m에 100개, 자갈밭 4.0 m에 200개)
1출력된 네 줄에서 평지 구간과 자갈밭 구간의 블록 수를 찾아 나눠보세요.
2자갈밭 구간은 길이가 오히려 더 짧아요. 그런데도 블록 수가 어떻게 되는지 보세요.

6강 한눈에 정리

  • 지형 생성 흐름은 새 스테이지 → World → 바닥 → 태양 조명 → 블록 배치 → reset 순이에요
  • 지형 블록은 물리 법칙을 따라 움직이는 Dynamic 대신, 제자리에 고정되는 FixedCuboid로 만들어요
  • FixedCuboid의 position은 중심점이라, 바닥에 붙이려면 Z를 높이의 절반 h/2로 둬요
  • 표면 성질은 friction(마찰)과 restitution(반발)로 정하고, density(밀도)는 물체의 무게를 정해요
  • 이중 for 루프가 블록 격자를 채우고, random.uniform()이 블록마다 높이를 새로 뽑아요
  • 조건을 매번 바꿔 학습시키는 도메인 랜덤화가, 처음 보는 환경에도 통하는 일반화로 이어져요
