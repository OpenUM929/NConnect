### 4-1. V1 `flat_orientation_l2` (배포 ⑥, 강좌 Go2 표에는 없음)
- **강좌·배포 예측**
  - 배포 ⑥: "강하게: 몸을 곧게 세워 험지·계단에서 덜 넘어짐 (대신 지형 적응 여지 축소)"
  - 생성기: "내림(강화): 꼿꼿·안정·소극", "올림(약화): 자세 자유·과감·등반"
- **원인과의 연결**
  - 식이 관측된 마지막 단계(옆 구름 = roll 각)를 직접 벌한다.
  - 남은 허용 항 중 표적 실패에 대해 강좌·배포가 직접 방향을 주는 유일한 항이다.
- **경쟁 예측:** "적응 여지 축소·소극" 쪽이다.
  - 계단 성공 로봇은 모서리에서 앞을 든다(pitch). 이 항은 그 동작도 벌하므로 계단 손실이 예측된다.
- **반례**(G-A047, A033 위 −0.5) [확인, `reports/GO2_REWARD_TRIAL_REFERENCE.md` §2]
  - 험지 옆걸음 낙상 59→60(무변화)
  - 10cm ≥2단 43→0, 15cm ≥1단 4→0
  - 계단 낙상 34→1, 90→8
  - 험지 전진 속도 0.366→0.192
  - "덜 넘어짐"은 계단 낙상에서 나타났지만 오르기가 사라졌다("소극"). 표적인 옆 구름은 줄지 않았다.
  - PC2 새 관측(꼿꼿해진 정책이 나빠짐)도 같은 쪽이다.
- **반례 반영**
  - 실패 예상을 먼저 적는다 [추정]: 옆걸음 낙상은 무변화, 계단 오르기는 손실.
  - 그래서 이 변수는 **한 노드로 끝낸다.** 기준선이 다르다는 이유로 반례를 무효로 보지 않는다.
- **값 −0.25 (시험 설계값)**
  - 유일한 관측값 −0.5의 절반이다. 오르기 손실이 나타나기 전에 강좌가 예측한 낙상 감소가 먼저 나타나는지를 가르는 폭이다.
  - "작아서 안전하다"는 근거로 고른 값이 아니다.
  - base_data: BETWEEN_OBSERVED(0과 −0.5 관측).
  - 시험 이력: 없음. 시험된 flat 값은 −1.0(A013·A025)과 −0.5(A047)뿐이다.
- **바깥 확장 없음:** 같은 방향의 다음 값 −0.5는 A047에서 이미 시험된 값이라 제외한다(§1-3).

**부모 규칙**
- 같은 변수의 값들은 같은 부모에서 비교한다.
- 실패한 자식 값은 다음 부모에 남기지 않는다.
- 서로 다른 변수의 승자를 검증 없이 한꺼번에 합치지 않는다. 승자는 순서대로 부모에 들어가고, 다음 노드가 그 부모 위에서 측정하므로 결합 효과가 측정된다.
- 앞 변수를 새 부모에서 다시 열지 않는다. 그래서 결과는 "그 부모 조건의 관측 최선"이며 항별 전역 최적이 아니다(상호작용 미측정).
- 실행 직전에 노드 값의 시험 이력을 다시 확인한다. PC1 G-A057 등에서 같은 값이 먼저 회수되면 그 노드는 §1-3에 따라 제외하고 다음으로 넘어간다.

**기타**
- TRADEOFF 노드는 부모로 쓰지 않고 보존한다. 표적 이득과 손실을 함께 기록해 최종 보고에서 따로 제시한다. 총점으로 상쇄하지 않는다.

### 12-4. R2 — 분류 우선순위 (위에서 먼저 걸리는 것으로 확정)
1. **INSUFFICIENT** — 다음 중 하나:
   - FULL_69_COMPLETE 아님
   - 보상 snapshot이 의도한 한 항 외에 부모와 다름
   - identity 불일치
   - report 누락
   - 비교 지표 결측
2. **WORSENED(정지)** — moving gate STATIONARY. 표적 개선이 있어도 이것이 우선한다.
3. **TRADEOFF** — 표적 하나 이상이 세 seed 공통 개선이면서, 동시에 다른 표적이나 보호 하나 이상이 세 seed 공통 손실.
4. **WORSENED** — 세 seed 공통으로 개선한 표적은 없고, 표적 또는 **보호**에 세 seed 공통 손실이 하나 이상.
5. **IMPROVED** — 표적 하나 이상이 세 seed 공통 개선이고, 세 seed 공통 손실은 없다.
6. **NO_CONSISTENT_CHANGE** — 나머지 전부. 세 seed 방향이 엇갈리는 혼합도 포함한다. 동등성이나 무효과를 증명하는 판정이 아니다. 초판의 FLAT을 이 이름으로 바꾼다.

**예상 판정 예시**

| 상황 | 판정 |
|---|---|
| 표적은 부모와 같고 10cm ≥2단만 세 seed 모두 감소 | 4 → WORSENED (초판의 FLAT→N4 경로는 결함이었다) |
| STATIONARY인데 표적 하나 개선 | 2 → WORSENED |
| 표적 낙상 seed 두 개 감소·하나 증가, 보호 손실 없음 | 6 → NO_CONSISTENT_CHANGE |
| 표적 개선 + 우회전 yaw RMSE 세 seed 증가 | 3 → TRADEOFF |

### 12-5. R3 — 승자는 직접 부모 대비 적격 후보에서만 고른다
- **적격 판정:** 같은 변수의 모든 후보를 먼저 **같은 직접 부모 대비** 12-4로 판정한다. IMPROVED인 후보만 적격이다.
- **적격 후보가 0개:** 부모를 유지한다. N3가 NO_CONSISTENT_CHANGE이고 N4도 적격이 아니면, 기본 승자는 부모 P이지 N3가 아니다.
- **적격 후보가 1개:** 그 후보가 새 부모가 된다.
- **적격 후보가 2개:** 형제 비교를 한다. N4를 N3 대비 12-4로 판정해 IMPROVED이면 N4, 아니면 N3다.
  - 형제 비교는 부모 대비 적격성을 통과한 후보끼리만 한다.
  - Codex 재현 예(보호 10/10/10 → N3 9/10/10 → N4 9/9/9)에서 N4는 부모 대비 세 seed 공통 손실이므로 WORSENED, 즉 부적격이다. 형제 비교에 들어가지 않는다.
- **누적 보고:** 최종 부모를 확정하면 P0 대비 누적 변화를 같은 규칙으로 따로 판독해 보고한다.

### 13-1. 35-R1 — 도달 뒤 정체는 노출 개체 수에 영향받지 않게 판정한다
**판정 지표(표적 투표에 쓰는 것)**
- `stalled_after_reach`를 투표 지표에서 뺀다.
- 대신 **"≥2단 도달 후 정체하지 않은 개체 수"**를 쓴다. 분모는 전체 32대로 고정하고, 값은 seed별 `reached_ge2 − stalled_after_reach`다(출처 `stairs_post_reach()`, `tools/go2_pc2_point_readout.py:445-484`). 증가가 개선이다.
- 기존 ≥2단 도달 수(32대 기준)와 함께 표적 T-G5로 쓴다.

**기술 지표(투표하지 않고 보고만 하는 것)**
- 도달 수, 정체 수, 조건부 정체율(= 정체 ÷ 도달).
- 도달이 0이면 조건부 정체율은 `NOT_APPLICABLE`이고 투표하지 않는다. 비교에 쓰는 비정체 개체 수는 0으로 정상 계산한다.
- telemetry 결측(steps.csv 없음, 열 결측, 손상)은 `NOT_APPLICABLE`과 다르다. 12-4의 INSUFFICIENT로 처리한다.

**예시 (각 seed 동일, 계약 테스트 목록에 추가)**

| 경우 | 부모 | 후보 | 비정체 개체 | 판정 |
|---|---|---|---|---|
| a | 1대 도달·1대 정체 | 10대 도달·2대 정체 | 0→8, 세 seed 증가 | 개선(손실 아님) |
| b | 10대 도달·2대 정체 | 1대 도달·0대 정체 | 8→1 | 손실. 정체 수가 줄었어도 개선으로 세지 않는다 |
| c | 0대 도달 | 0대 도달 | 0→0 | 변화 없음. 조건부 정체율은 양쪽 모두 NOT_APPLICABLE |
| d | 0대 도달 | 3대 도달·3대 정체 | 0→0 | 변화 없음. ≥2단 도달은 0→3으로 개선 투표 |

### 13-2. 35-R2 — 모든 손실은 실제 비교 부모의 같은 seed 값 대비로 판정한다
**seed별 악화 정의**
- 낙상 수: 후보 > 비교 부모
- 생존·진행 비율·`recovery_rate_upright`: 후보 < 비교 부모
- RMSE·명령 오차: 후보 > 비교 부모

**공통 손실**
- 세 seed 모두 악화일 때다. 크기 문턱은 새로 만들지 않는다.
- "≥1"은 비교 부모가 그 seed에서 0일 때 위 정의가 갖는 특수한 경우일 뿐이다. 별도 기준이 아니다.

**비교 부모**
- 직접 부모 판정에서는 그 노드의 직접 부모다.
- 형제 비교에서는 비교 대상 형제다.
- P0 누적 판독에서는 P0다.

**예시**

| 비교 | 값 | 판정 |
|---|---|---|
| P2 대 P0 (P0=(0,0,0)) | P2 낙상 (1,1,0) | 두 seed 악화 → 공통 손실 아님 |
| N5 대 P2 | N5 (1,1,1) 대 P2 (1,1,0) | seed 303만 악화 → 공통 손실 아님 |

- 공통 손실이 아닌 일부 seed 악화도 숨기지 않는다. 판독에 "일부 seed 손실"로 값과 함께 따로 적는다(기존 판독기 `protection` 출력 형식).

### 13-3. 35-R3 — 성능 결과와 실행 오류를 분리한다
**성능 결과에 따른 이동(§12-7 그대로)**
- TRADEOFF, WORSENED, NO_CONSISTENT_CHANGE, IMPROVED에 따라 이동한다.
- 변수 종료 후 다음 변수로 가는 것은 TRADEOFF와 WORSENED일 때(그리고 N4·N6을 마친 뒤)뿐이다.

**같은 값 이력으로 제외될 때**
- 실행 오류가 아니다. §12-6의 우회 규칙을 따른다: 선행 노드가 제외되면 의존 자식은 실행하지 않고 그 변수를 종료하며, 다음 변수로 간다.

**실행 오류 처리(대체 표)**

| 시점 | 처리 | 다음 변수로 진행 |
|---|---|---|
| 학습 시작 전 실패(rc 20~23, 학습 미발생) | 환경을 고친 뒤 그 노드를 처음 시작한다. 재학습이 아니다. 고칠 수 없으면 보고하고 멈춘다 | 하지 않음 |
| 학습 완료 후 수집 실패(고정 iter checkpoint와 pin 존재) | 기존 checkpoint를 보존하고 재학습 없이 평가·회수만 복구한다(runner resume) | 복구에 성공하면 정상 판독 후 성능 규칙대로 |
| 위 복구 실패 | `INSUFFICIENT_UNRECOVERABLE`. 새 학습을 시작하지 않고 트리를 멈춘다. 사용자에게 보고한다 | 하지 않음 |
| 학습 도중 실패(고정 iter checkpoint 없음) | `INSUFFICIENT_UNRECOVERABLE`. 자동 재학습 없이 트리를 멈추고 보고한다. 같은 값 재학습 여부는 사용자가 정한다 | 하지 않음 |

**바뀌는 트리 문장**
- §12-7 트리의 "TRADEOFF / WORSENED / INSUFFICIENT(복구 불가) → V2 종료"는 다음 두 줄로 바꾼다.
  - "TRADEOFF / WORSENED → V2 종료, P2 = P0, V3로"
  - "INSUFFICIENT_UNRECOVERABLE → 트리 정지·보고"
- 표의 "그 밖 → V3"도 "TRADEOFF·WORSENED → V3 / INSUFFICIENT_UNRECOVERABLE → 정지"로 읽는다. N5·N6 행도 같다.
- §8 중단 조건의 "같은 노드가 수집 실패로 두 번 INSUFFICIENT"는 위 표로 대체한다. 다른 중단 조건은 유지한다: 시작 단계 실패 보고, 사용자 마감, GPU 경보는 보고만.
